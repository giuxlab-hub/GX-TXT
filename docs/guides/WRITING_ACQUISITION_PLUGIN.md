# Writing a GX-TXT acquisition plug-in

GX-TXT Pipeline v0.8.9 can add new acquisition formats without modifying core dispatch. Use **Acquisition Handler Plugin API v1**.

## Directory

```text
plugins/modules/acq.my_format/
  module.ini
  README.md
  runtime/
    acquisition_handler.tcl
```

## Descriptor

```ini
[meta]
api_version=1
id=acq.my_format
kind=acquisition
group=Instruments / Importers
name=My format importer
version=1
runner=standard_tcl
order=100

[inputs]
contracts=raw.my_format

[outputs]
datasets=timeseries.table
files=datasets/*;metadata/datasets.ini

[config]
fields=dataset_id

[config.dataset_id]
type=string
label=Dataset ID
default=my.dataset
required=1

[runner]
handler=my_format

[acquisition_handler]
api_version=1
script=runtime/acquisition_handler.tcl
inspect_proc=::MyFormat::inspect
import_proc=::MyFormat::import
file_label=My format files
file_patterns=*.txt;*.dat
supports_batch=1

[documentation]
api_version=1
guide=README.md
api_refs=MODULE_API_v1;ACQUISITION_HANDLER_PLUGIN_API_v1;DATASET_API_v1
```

## Inspection callback

Inspection is for recognition, metadata, variables and preview only:

```tcl
namespace eval ::MyFormat {}

proc ::MyFormat::inspect {request} {
    set source [dict get $request source_path]
    # Parse only enough to identify format, metadata, columns and sample rows.
    return [dict create \
        recognized 1 \
        format my-format-v1 \
        metadata [dict create instrument "Example logger"] \
        variables [list \
            [dict create source_column 1 original_header Time canonical time_s unit s semantic_role time] \
            [dict create source_column 2 original_header Current canonical current_A unit A semantic_role measure]] \
        preview_rows [list [list 0 0.1] [list 1 0.2]] \
        warnings {}]
}
```

## Import callback

Import receives the framework session, RAW snapshot, output directory, current variable aliases and descriptor configuration:

```tcl
proc ::MyFormat::import {request} {
    set outdir [dict get $request output_dir]
    set id [dict get $request dataset_id]
    set rel "${id}.csv"
    set dst [file join $outdir $rel]

    # Parse RAW and write the canonical file.
    # Do not edit metadata/datasets.ini.

    return [dict create datasets [list [dict create \
        dataset_id $id \
        contract timeseries.table \
        format csv \
        path $rel \
        variables {time_s current_A} \
        units {s A} \
        semantic_roles {time measure} \
        source "My instrument" \
        provenance "Parsed from vendor export"]]]
}
```

## What the framework does afterward

GX-TXT validates the returned file, calculates hashes, registers the dataset, saves `datasets.ini`/manifest, refreshes Results/Variables/Analysis-source selectors and owns session lifecycle.

If the canonical Dataset needs stable public variable IDs, add an optional
`variable_schema` list to its returned descriptor. Each entry declares a
`variable_id` and, for CSV, the one-based `source_column` and canonical header.
You may also declare Dataset Variable Schema v3 types, dimensions and coordinate
relationships. CORE checks the payload and commits the declaration with RAW,
Dataset registration and optional `structured_metadata`. Existing handlers
without this field keep generated IDs such as `v0001`. See the Acquisition
Handler API reference for the complete field and rollback rules.

## Do not do this in a plug-in

- do not create a GX-TXT session;
- do not call `datasetRegister`;
- do not edit `metadata/datasets.ini`;
- do not add a core `elseif` for your format;
- do not hide scientific interpolation/join/resampling in acquisition code.

See `docs/api/ACQUISITION_HANDLER_PLUGIN_API_v1.md` for the complete normative contract.

## v0.9.0 capabilities

For batch chooser integration, progress/cancellation callbacks, cooperative streaming, preflight, multi-file grouping, non-CSV canonical preview, MIME/format metadata and instrument suggestions, see:

- `docs/api/ACQUISITION_HANDLER_PLUGIN_API_v1.md`
- `docs/api/ACQUISITION_HANDLER_CAPABILITIES_v1.md`
- `docs/guides/ACQUISITION_MULTI_SOURCE_WORKFLOW.md`

Do not add format-specific branches to `gxtxt_pipeline.tcl`.

## Binary acquisition sources (v0.9.5)

For a binary source, declare:

```ini
[acquisition_handler]
source_kind=binary
```

Do not decode or render the source in the framework. `inspect_proc` receives a framework-owned `preview_dir` when the Preview workspace is active. Return Preview Descriptor API v1 metadata and/or an artifact generated by the plugin. A binary canonical dataset returned by `import_proc` should set `storage_kind=binary` and an appropriate `media_type`.
