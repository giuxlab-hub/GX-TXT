Terms that carry different scientific meanings

Original raster position
A point in the source image coordinate system. Display zoom, pan or opacity does not redefine it.
Scientific coordinate
A calibrated value with axis meaning, units and a specific mapping. A different accepted calibration can map the same raster point differently.
Proposal and accepted points
A tracing proposal awaits deliberate review and acceptance. A visually plausible route does not establish the intended scientific curve.
Active, accepted and selected calibration
Distinct roles for the current working mapping, reviewed measurement state and requested publication set. Keep the actual identities and roles explicit.
Curve identity and display name
A stable identity groups scientific points. An editable label is presentation and must not replace that grouping identity.
Canonical Dataset and Preview
The Dataset is the published scientific resource. Preview is its supported consultation, with its own representation/status; a visible frame does not replace canonical data or their provenance.
Quality diagnostic and measurement uncertainty
A structural or image observation describes evidence and limitations. A standard uncertainty needs a justified statistical model and the supported scientific contract.
Stroke width and localization uncertainty
Ink thickness in original pixels is descriptive geometry. It does not automatically supply a standard deviation for the centerline.
Source claim and owner observation
A provider field must retain its actual meaning. An independent host receipt applies to its observed source identity and preparation time, with explicit unsupported or unverified states.
