# Working directory profiles

Use a working-directory profile when different projects repeatedly use different input, session, manifest, and export trees.

Example workflow:

1. Open `Directories...` from the top `Workspace` controls.
2. Enter `REATTORE` as the profile name.
3. Set the acquisition/CSV directory, Session root, Open-session directory, Manifest directory, and Export/PDF directory.
4. Click `Save / update profile`.
5. Later choose `REATTORE` and click `Load`.

Loading the profile changes future file-dialog starting directories and new-session/export roots. It does not modify an already open session.
