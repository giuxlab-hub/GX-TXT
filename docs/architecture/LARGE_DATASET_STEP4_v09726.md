# Large Dataset Step 4 - GX-TXT 0.9.7.26

Consumers and producers declare hard capabilities and preferences. CORE Storage Auto filters and ranks the installed CSV, HDF5, and future providers. The current representation is reused when it satisfies the request; otherwise CORE creates or reuses an optional session cache through the existing Canonical Dataset v2, Table Stream v3, and Publication v2 provider infrastructure.

Publication creates a new scientific Dataset. Materialization creates a physical access representation of an existing Dataset. Dataset and Variable IDs remain unchanged.

Policy v1 has no data-size threshold. Its stable tie order preserves ordinary CSV workflows. HDF5 follows naturally from direct random range, multidimensional, group, typed numeric, or hyperslab requirements.

Cache identity includes payload, schema, provider/version, format/version, policy/version, and conversion parameters. Atomic construction, integrity checks, reuse, invalidation, independent deletion, and rebuild after session copy keep caches optional.

Step 4 excludes scientific-module migration, plot LOD, indexed CSV, mmap, NetCDF, and Zarr.
