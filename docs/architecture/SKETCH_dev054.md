# dev-054 retained sketch constraints and dimensions

Native2D remains the sole geometric authority. This cycle extends the existing scene/rule IDs, retained definitions, encoded stable controls/segments, Unit Registry, Interactive Documents, Undo/Redo, recovery and Script Bridge. There is no separate sketch geometry, dimension identity, constraint store or publication authority. Dataset, Native points and retained primitives retain their different scientific semantics.

`gx2d_sketch_solver.inc` adds bounded local solving on deep candidate definitions in the enabled connected component. Variables are retained control coordinates, round radii, ellipse radii/rotation, rectangle rotation and arc start/sweep. Existing affine matrices define the local parameter chart; gizmo transforms compose the existing matrices. Fixed whole objects and locked objects contribute no movable variables; fixed controls contribute position equations. Finite-difference Jacobians and damped least squares solve residual equations. Only convergence plus existing complete-scene validation permits adoption; failure restores candidate definitions, caches and rule state, leaves output IDs untouched and creates no history. Hard defining-control goals preserve free DOFs and reject incompatible goals; radius/axis/arc edits preserve the edited primitive's center. Explicit definition edits hold changed parameters as goals. Legacy generic scientific point operations preserve their atomic validation semantics.

Horizontal/vertical, point coincidence, parallel/perpendicular, segment equality, round-radius equality, midpoint, concentricity, collinearity, point-on-line/curve, supported symmetry, tangency, G2 and dimensional equations use mathematical definitions, not render samples. Line tangency respects a finite segment (construction lines use the supporting line); arc contact respects its finite angular domain. Round tangency selects the nearest internal/external branch and persists it. Bézier/Spline endpoint jets reuse exact native evaluation and analytic second derivatives; Catmull-Rom jets come from the existing cubic-piece authority. G2 matches position, tangent direction and signed curvature; it is distinct from G1. Point-on-curve witnesses use exact native evaluation with a bounded numerical closest-parameter search; no sampled curve is promoted to an exact primitive.

Limits:64 connected objects,256 scalar parameters,1024 scalar residual slots,100 solve iterations. Unsupported, singular/nonconvergent or out-of-range cases return explicit rejection. Local Jacobian rank is a diagnostic at the current configuration, not a proof of global uniqueness. `analysis_complete=0` identifies legacy/generic components whose DOFs this solver cannot completely analyze; the palette never labels those fully constrained. Unsupported symmetry families (arc, ellipse, rectangle, non-similarity round definitions) remain excluded. General global solving, numerical conditioning across extreme scales and dimensional parameter expressions remain future work.

Dimensions are existing relationship IDs with additive `gx2d_relationship_state`: solved/driven/placed flags, annotation world XY, tangent branch and inverse-length curvature tolerance. Numeric value and annotation placement are independent. Driving rules govern geometry; reference rules measure it without solver rows. A redundant driving dimension is detected by local rank and rejected atomically; the inline UI offers an explicit reference alternative. Restore creates a satisfied relationship using the saved geometry/state and existing identity allocator; it does not replay a driving edit. Existing constraint capture/Document restore serialize the additive fields. Coordinate reexpression scales linear values, anchors, annotations and curvature tolerance consistently while keeping angular tolerances in radians.

Public additions keep old constraint POD ABI and enum numbers1..21. New kinds22..27 are horizontal/vertical distance, point-line distance, parallel-line distance, axis angle and curvature. Public component, status, solve-control/definition, create-state, relationship-state/hit and dimension inference/preview/apply/primitives APIs belong to CORE. Eight additional scoped safe operations use existing execution-owned object/constraint tokens in Python and Octave. No raw pointers or foreign scene references cross Script Bridge.

Workbench Tcl implements input dispatch, selection staging, palettes, original symbolic badges, overlays, font/layout extents and inline entries. CORE infers dimension type, evaluates witnesses/arcs/arrows, resolves stable references and performs hit testing. The old tiny-current-tag click route is removed. Defining handles take precedence over nearby annotation regions; Ctrl/Shift preserve graphical reference selection. Double click respects active creation/constraint tools and modifiers. Rejected edits explicitly reset to Select, cancel the Native drag, discard previews/captured references and thaw controls. Routine target changes preserve a clean active Move tool; Escape always returns to Select.

`gx2d_relationship_hit_score` ranks overlapping labels by device distance to their centers ahead of witness-line hits; the renderer supplies measured font bounds. Tcl routes to the winning existing relationship ID, without its own geometric proximity calculation. Tab cycles coincident/overlapping markers. Routine gesture cleanup preserves ordinary defining-reference selection, which the existing endpoint Join workflow requires; rejected edits and Escape still discard captured interaction state.

Parallelism assessment: each bounded sketch component solve is a coupled, small transaction against one scene. Running equations or candidate edits concurrently would add overhead and complicate atomic ownership. It stays serial. Independent scientific fitting/bulk work retains the existing Parallel Execution/resource policies; no private worker pool was introduced.

Normal inspector is a Workbench child frame, hidden rather than destroyed. Tree updates preserve rows instead of repeatedly deleting/reselecting them; queued callbacks validate widget/record existence. Advanced forms use the Workbench toplevel as their parent. These changes fix the destroyed `.curve_workbench.constraints` transient parent and prevent it from remaining normal-use state.
