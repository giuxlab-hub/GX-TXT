# Integrated Debian workflows

Markdown Dataset Open defaults to rendered CORE Markdown. Runtime associations
for Markdown and HTML default to internal; an explicit executable argv prefix can
select an external viewer. Source language settings do not appear in rendered
Markdown mode. Native C renders bounded, inert HTML and structured XML; scripts,
DTD/entities, external assets and network execution are inactive. HTML Viewer is
an official CORE Viewer with its own public rendering API.

Text and Source Code Importer distinguishes canonical Dataset versus registered
Session script. Auto Python creates a Session-owned script without executing it.
Ambiguous .m requires explicit Octave language and destination. Source publication
stays within the selected Session and preserves source bytes/provenance; UTF-8 BOM
handling is documented in the import metadata. Invalid IDs are errors before
publication. Cooperative imports pin Session identity and roll back on cancellation
or Session switch; configured default/profile roots are not rebound to the Session.
Successful new imports retain acquisition receipts; old Sessions truthfully state
when their historical operation status was never recorded.

Results uses independent checkboxes, category/search filters and bounded pages.
Focus and row selection do not toggle a result. Check several results to compare;
Copy checked results copies that consultation only. Imported canonical data,
registered Session script imports, legitimate user Jobs, Viewer publications and
descriptor-declared scientific reports are visible. Authenticated private Preview
workers/cache/technical source trees are absent. A modified legacy service-named
script is a recorded identity conflict, never silently reclassified as a user edit.

Python/Octave Script Workspaces retain their existing Registry/property shells and
share one editable source component. Fresh/load/save establish an exact source and
property baseline. Edit/Undo/Redo determine dirty state; highlighting, folding,
selection and palettes do not. Imported unsaved editor drafts remain dirty.

Run → Debug opens an embedded native debugger. Save a clean Session script, set
physical-line gutter breakpoints, then Start Debug. Into/Over/Out/Continue/Pause/Stop
control the actual managed Python bdb or GNU Octave debugger. Stack/locals/globals
are bounded observations; opaque objects never invoke a Python user repr. Edits,
source revision or Session changes prevent stale stepping. Closing the panel
cancels an active owned Debug Job; normal noninteractive Run keeps its prior owner.
A paused debugger has a 600-second lease. Advanced breakpoint relocation and some Pause/fault combinations are not yet fully verified; refer to local acceptance records for validation details.

Execution Details offers actual Program output, Program stderr, Diagnostic log and
truthfully labeled Legacy combined stream. Selection copy follows focus. Copy
entire source, Save source to file and explicit Publish source as Dataset target
that selected stream. Exports are atomic and preserve source bytes; clipboard
text is UTF-8 with incomplete scalars carried between pages. Legacy merged logs
are not guessed apart. Publication requires an explicit new Dataset ID and a
terminal user Job in the selected Session. Private service streams are not
ordinary publishable user outputs. Runtime diagnostics and scientific Dataset
publication remain distinct actions.
