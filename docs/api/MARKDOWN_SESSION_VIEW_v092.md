# Rendered Markdown in Session files — v0.9.2

Markdown/GX-Markup note files (`.md`) inside a GX-TXT session are rendered by default in the **Session files** viewer.

The normal read-only view does not expose source markers such as `#`, `**...**`, backticks, or `[color=#RRGGBB]...[/color]`. The existing GX-Markup renderer is reused so headings, emphasis, code, and colors are shown as formatted text.

Use **Edit note...** to open the source markup in the GX-Markup editor. Non-Markdown files keep the historical plain monospaced Session files viewer.
