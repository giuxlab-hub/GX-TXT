# Reference-data rights classification (checked 2026-09-24)

| Source | Classification and handling | Authority |
|---|---|---|
| TUM RefIMP | **A: CC-BY-SA-4.0** on the dataset record. Download and converted-library redistribution are permitted subject to attribution, source/license link, change indication and share-alike obligations. Native files and GX-TXT libraries carry source and license metadata. | https://mediatum.ub.tum.de/1656656 ; https://creativecommons.org/licenses/by-sa/4.0/ |
| OpenSpecy package example versus OSF spectral library | Package `DESCRIPTION` declares CC BY 4.0; that alone does not establish the rights of every third-party spectral record in the evolving OSF library. **E: unclear for bulk library data** until item-level licensing/ownership is audited. No bulk acquisition or redistribution was performed. One package example JCAMP whose own header declares `OWNER=Public domain` was converted into a separately identified local one-spectrum library; this classification applies only to that item. | https://github.com/wincowgerDEV/OpenSpecy-package/blob/main/DESCRIPTION ; https://github.com/wincowgerDEV/OpenSpecy-package/blob/main/README.md |
| NIST Chemistry WebBook / SRD 69, including the named PNNL/IARPA, quantitative and evaluated IR collections | The WebBook marks SRD data copyright/all rights reserved and credits collection-specific authors. **E/D for bulk redistribution** pending specific permission or license; an individual water JCAMP was used solely as a parser fixture. Do not mirror its 16,000+ IR records. Recheck each collection's terms before local systematic acquisition. | https://webbook.nist.gov/chemistry/ |
| AIST SDBS | The official FAQ permits downloading spectra for noncommercial class notes, textbooks and scientific publications with citation, but says it generally does not supply spectra as digital data. **C: manual/individual academic use only here**; no automated bulk acquisition. Seek AIST permission for a digital or systematic collection. | https://sdbs.db.aist.go.jp/Htmls/faq_eng.html ; https://sdbs.db.aist.go.jp/Disclaimer.aspx |

Public web accessibility is not a bulk-redistribution license. Do not place restricted source payloads in public plugin or framework archives. This is an operational rights audit, not legal advice; re-evaluate official terms before each update.
