# Analysis modules

Select an enabled analysis module and its canonical Dataset sources. The module configuration shows parameters and variable bindings. Where a module accepts several sources, assign a Dataset to each declared Source ID.

Use Run to review and execute the configured work. Standard Octave modules run through the checked framework runner. A run fails if execution fails or required declared outputs are missing. Published results are available through the Dataset registry, Session files and relevant plots.

Module-specific scientific meaning, assumptions and output interpretation belong to the plugin manual. Select a module in **Modules** and choose **Open module manual...** to read it here.

Choose modules in **Modules → Module State** or use the independent Plot,
Script Octave and Script Python checkboxes. Disabled modules retain saved scientific
state and disappear from Analysis. Install/update/remove plugins through
**Configuration → Modules → Plugin Manager…**.
