# Getting started

GX-TXT organizes scientific work in Sessions. Create or open a Session from the Session bar, then import source files in **Acquisition**. The source files remain unchanged; GX-TXT publishes canonical Datasets with provenance and variable schemas.

Select modules in **Modules**, then choose their Dataset sources in **Analysis**, configure its sources and parameters, then use **Run** to execute it. Inspect outputs in **Datasets**, **Plots**, **Viewers**, and the **Sessions** file browser. The Session carries its metadata, scripts, analyses and output artifacts.

The main paths through the framework are documented in [Sessions](sessions.md), [Acquisition / Import](acquisition.md), [Analysis modules](analysis.md), and [Scripting](scripting.md). Module manuals are listed under Plugin manuals in this browser.

Save or export a Session when you need a portable record. The offline HTML export is a read-only view and does not replace the Session archive.
