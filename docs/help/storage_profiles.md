# Storage Profiles

In Configuration → Storage, select a saved row to inspect/edit its five directories.
The bold heading identifies what is applied; selecting a row does not apply it.
New creates a draft, Save saves it, Save & Apply saves and uses it, and Cancel / Show
applied discards draft edits. All saved profiles are in the expanding catalog below.
Scroll horizontally for directory columns; the five fields expose each full value.
Use Show Storage defaults & cache settings for the established default/cache controls.

In Sessions → Configuration / Manifest → Storage Profiles, the five initial fields
show actual effective directories, with Global/Private/fallback sources. Use global
profile is one direct action after choosing a global name. Create independent private
copy proposes that name; an existing private copy is never overwritten. Global/private
names may match. Private copies do not synchronize with their original globals.
Select a private row then Use selected private, or Edit private copy. Blank roles fall
back to global. @session/relative/path resolves in this Session; create that directory
first or choose it with Browse. Save private and Save & Use private are distinct.
Cancel returns to effective directories. Remove confirms and keeps directory contents.

A readable operation dialog preserves failed edits. Correct the name/path, select the
existing row for an intended update, or cancel the draft. Profiles store directories
only and never move a Session or copy scientific Datasets/Workspaces/graphs.
