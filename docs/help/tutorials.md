# Tutorials / DEMOs

DEMO Sessions provide worked examples. Some DEMOs have Session Generators that recreate the Session into a clean destination. A generator carries its own scientific data and does not require an installed analysis module to generate the Session.

Open a DEMO copy for exploration. Use the module's manual for its analysis method and the Session Generator's documentation for reproducibility. Installed plugin tutorials and Markdown examples appear in this browser when declared by their descriptors.
