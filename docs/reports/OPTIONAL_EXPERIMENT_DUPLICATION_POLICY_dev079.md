## Result and contract

Duplicate Experiment reliably completes with clean state even when optional modules
lack a policy. Selectable modules reset to descriptor defaults, disabled, with empty
Run selection and scientific/path input bindings. Nonselectable CORE services retain
normal availability. Unknown/mixed/stale optional payloads omit with owner/reason
reports. A user can configure fresh input and run the unchanged module normally.

The optional versioned `EXPERIMENT_DUPLICATION_POLICY_API_v1` supports static Module
INI copyable setup fields, valid independent external files, exact document provider/
schema/version actions, inert code envelopes and bounded explicit preparation file
ownership. Tcl/public Python/Octave discovery and validation require no global GX-TXT
version pin. No executable callback, installation gate, plugin-private filesystem clone
engine, alternate document registry or resource store was added. CORE owns safety and
transaction. See the normative manual and module author guide.

Classification at document creation is recorded in the existing registry, bound to
owner/schema/version/generation. Valid preparation receipts survive compatible updates
and provider uninstall. Updates preserve receipts; payload/resource hashes and current
owned dependencies are checked at duplication. Unknown old objects require an installed
exact declaration or narrow documented native schema adapter; otherwise omit.

Registry IDs/revisions/generations/provenance survive in an independent Session lifetime.
Only live referenced Managed Resource blobs are copied. Dependency omissions propagate
to a fixed point across documents and Viewer layers, preventing orphan resources/layers.
SHA-256 validates bytes only; independent preparation with identical Dataset bytes stays.
No author code/parameter substring relocation occurs. Source-dependent module values
reset instead. General notes, scripts, actual instrument/Library snapshots and independent
Session parameters survive; uncertain module-scoped parameter overrides reset.

Source Dataset scientific payload/registration/metadata, Workspace documents/resources/
History/geometry and all existing graph definitions/Series/Variants/axes/legends/styles/
annotations/hidden transport/results are excluded globally, overriding every declaration.
Observations are empty in cfg/Manifest/file/editor. Unknown analysis/raw/channel/cache/
report/log and metadata/loose state omit conservatively rather than retaining stale
scientific residues. Existing author notes/script authorities, declared owner files and
proven document/resources/Viewer artifacts supply retained preparation ownership.
No Workspaces are converted, migrated, reconstructed or partially retained.
