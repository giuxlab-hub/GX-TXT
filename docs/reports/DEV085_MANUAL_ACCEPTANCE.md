# dev085 manual acceptance

Open an existing Project Session, go to Sessions and click **⌂ Project Home**.
Confirm Projects selects the associated Project and open Experiment.

Save Session configuration, select its Project and **Export Project…** to a new ZIP
outside the Project. On the other installation/context choose **Import Project…**,
select the ZIP and optionally enter a name. Confirm the new Project includes all
Experiments. Open its Sessions, inspect scientific data, Save, restart and reopen.
Origin retains the original creator and source IDs with local receiver events.
A corrupt package must show an error without registering a partial Project.

Module snapshots are inert Project resources. Missing/different installed runtime
modules are reported by existing diagnostics; use existing plugin management if
needed before running them. Do not import a Project by opening its ZIP as a Session.
Manual acceptance is PENDING; engineering PASS does not imply user acceptance.
