## Performance and failures

Visible Preview measured 30 retained toggles, mean about 4.1 ms, with zero table reads,
CurveSource opens, authority workers and native create/configure calls; token, point
count and axes were stable. This is measured interaction, not initial preparation.

The final 20K native grid impact test measured 57.698/60.703 ms median/maximum of five
30-wheel-event bursts, including xdotool and 40 ms settle. Identical immutable dev101
measured 46.324/46.368 ms. The added functionality has measurable overhead; it remains
bounded and responsive in this test. Whole-application RSS was about 276300 versus
275444 KiB, not a memory-improvement claim. A pre-deposit visual review also corrected the Script editor displaying its encoded
Workbook result payload; it now shows readable diagnostics/proposal status while
retaining the complete original Job log. Actual rotated/wrapped-cell Auto-fit was
verified through the shared toolbar without changing neighboring rows.

The first dev102 attempt measured about
710 ms: navigation extent was scanning all cells on scrolling. Caching that existing
presentation extent by Workbook identity/sheet/revision corrected the regression.
Native row-height prefix offsets similarly avoid repeated full sparse-map scans.
Whole-visible-viewport painting remains the earlier explicit regional-painting debt.

Earlier failing receipts are genuine and retained: transport dictionary conversion,
source-order test naming collision, layout/popup event handling, source-resource path
lookup, malformed validation fixtures and original unimplemented paths. Core-02 was
terminated by a mistakenly invoked existing deliberate SIGKILL crash hook; it is not
a passing rollback test. Real controlled exception rollback passes separately.
A same-Session idempotent reopen test incorrectly expected a new token; corrected
actual Session switching verifies the real lifetime guard. Source-review-01 retains
missing/not-yet-written/new-link findings; preexisting historical broken README links
are separately classified. No failed attempt is relabeled PASS or discarded.
