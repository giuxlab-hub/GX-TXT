# Shared Workspace GUI host — implementation and verification

The embedded Session Workspaces view, top-level manager and Viewer Workspace menus use one host action/state dispatcher. Existing Session Workspace, Interactive Document, managed resources, descriptor action and scientific History authorities continue to own scientific state. Curve Viewer and Dataset Curve Fit adopt optional host lifecycle callbacks; Curve Workbench retains its specialized geometry/Undo controls, while Interactive Curve Builder and Scientific Image Inspector retain their compatible four-callback adapters.

The manager provides provider/text filters, selection-dependent controls, naming forms, New/Open/Save/Duplicate/Rename/Close/Delete/Notes/Preview/Import/Export/Refresh and existing descriptor Actions. Names and notes remain ordinary existing metadata. New drafts are unregistered until Save or a genuine scientific edit through the existing autosave owner. Naming cancellation and Rename do not silently save a draft. Saved selection receipts bind Session token, host window incarnation and Document generation/revision. Metadata-only revisions refresh the existing idle signature. Destroyed windows release weak subscriptions.

Curve Viewer and Fitter use Save/Discard/Cancel before transitions with remaining uncommitted edits. Fitter's field owner suspends FocusOut commits while that review owns focus. Explicit Save validates and invalidates the previous Preview through the existing field owner exactly once. Discard cannot trigger a delayed FocusOut save while closing. No fitting, numerical engine, scientific History implementation or canonical Dataset storage was replaced.

Focused real Debian GUI evidence is retained externally under `_evidence_official_dev099`. `workspace-gui-02` verified both actual Viewers' New/Save and a canonical Curve Viewer source; its later synthetic key event lacked focus. `workspace-gui-03` verified live filtering/reset, provider scope, bounded managed preview, missing/corrupt preview reporting and repeated UTF-8 note saves. It then exposed a genuine missing revision field in the existing idle signature. `workspace-gui-04` continues only unfinished actions and verifies that correction, Rename/title, duplicate-name refusal, nested-resource Duplicate, actual file chooser Export/Import, exact Open, Delete Cancel/confirm, clean reopen, stale revision refusal and unchanged source SHA. Its 18 checks pass.

`workspace-lifecycle-01` verified actual Curve draft Close Cancel/Discard/Save and detected the Fitter modal FocusOut issue. `workspace-lifecycle-02` reuses a private saved fixture and passes 14 affected field-draft/Save/Discard/Cancel, reopen, unavailable-provider, stale Session/form, disabled Save, safe stale-close, subscription cleanup and source-integrity checks. Existing model-selection autosave remains an intentional provider edit, so the Discard baseline is captured after that explicit committed selection and before the uncommitted text edit.

`workspace-api-02` passes seven focused generation/revision, nested-resource remapping, precommit foreign-provider import refusal, notes ownership and source-SHA checks. `workspace-identity-03` verifies final module/package/runtime identities and required framework compatibility, actual module inventory and no new Tcl rename wrapper chains in changed owners. These are host/API checks, not a numerical fitting campaign or broad Viewer retest. Existing wrappers were preserved because removing their wider historical call chains is outside this bounded GUI ownership change.

All first failures remain recorded, including the initial numeric-versus-hex XID comparison (fixed before GUI02), a Unicode fixture that omitted binary UTF-8 encoding, the missing idle revision field, the FocusOut review issue and two identity-fixture mistakes. No failing process is relabeled PASS. The final external `workspace-final.json` binds exact evidence paths/hashes and source changes. Original Session/Dataset files, independently maintained plugin ZIPs, accepted archives and the mutable user installation were not edited by this workstream.
