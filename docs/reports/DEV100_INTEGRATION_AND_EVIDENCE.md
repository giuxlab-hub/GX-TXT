# Official dev100 implementation and focused evidence

The isolated candidate derives from the deposited official dev099 archive
`c16819ac88d63fc675da3a76ad9de09651df2e9538365eaa8fd514f63ea1768f`.
The mutable user installation is not a development baseline. The original large
dev098 master task and both user-supplied independent plugin ZIPs are preserved.

Worksheet integrity is recorded item by item in the WS-01–WS-32 source inventory
and current matrix. Typed values, formulas, units, named ranges, source bindings,
structural references, clipboard, scientific Jobs, publication and resource
ownership use their genuine public authorities. Save adopts historical Workbook
Documents through the existing same-ID Workspace authority. Large History
snapshots use existing managed Document resources and portable dependency remaps.
The independent Session Generator consumes public Worksheet APIs and supervised
Script Jobs; it does not write private Workbook state.

The grid is a real Native2D C++ Tk/Cairo device surface, shared with native Plot
presentation. No cell-per-widget grid, scientific storage engine, independent
History or new Job supervisor was introduced. Actual Debian pointer/keyboard,
four-size layout, fill/reference/clipboard, source lifetime, Workspace and
Configuration receipts are retained. The final 20,000-row five-sample wheel
benchmark measured p50 46.304 ms and p95 46.500 ms against dev099 427.532 and
431.334 ms. Each measurement includes 30 real events, process launch and a 40 ms
settle; p95 is the maximum of five samples. Whole-process RSS was 274,560 KiB
versus 225,640 KiB. No memory improvement or isolated drawing speed is claimed.
The original slower native attempts remain in the evidence.

The native host coalesces requests and repaints the bounded visible viewport to
one Cairo backing pixmap. It does not implement dirty-tile/rectangle-only
invalidation. This is an explicit noncritical optimization deviation retained in
the dev102 backlog, not a claim of completed regional painting; no scientific
values or viewport identities depend on a tile cache.

Plot Dataset v4 is additive. Existing v1/v2/v3 source, original bindings and
runtime files remain byte-identical. Native2D C++ handles the actual ten 2D kinds;
Native3D C++/VTK handles the actual seven 3D kinds. The finite method, companion
and capability matrix identifies implementation owners and named verification.
Canonical rank2 grids use explicit dimensions and coordinate identities; rank3
is not invented as an accepted old contract. Existing unit/coordinate/level
transforms and error semantics remain authoritative. Native exports, source-row
indices, independent representations and Python/Octave Jobs have focused receipts.

The existing Graph metadata declares native ownership. Plots configuration is a
read-only projection of existing global/module/Variant/Axes/Legend/layout owners.
Rerender uses the existing Analysis queue. Native Clone and portable transport
capture complete canonical Dataset ZIPs and inert checked manifests, including
exact identities and SHA-256. Malformed dictionaries, undeclared files, unsafe
paths, nested Graphs and different Dataset identities were rejected; command-like
label text stayed inert. Explicit rendered-only import removes native scientific
ownership. Capture staging includes the actual coordinate-metadata sidecar.

Live Worksheet charts retain exact typed lineage and original source ordering,
convert only display units, preserve NaN breaks and complete finite bounds, and
publish immutable canonical Datasets/Graphs. Real GUI evidence includes source
selection, move/resize, properties, pointer zoom/pan/Fit, multiple charts, same-ID
Save, Session reload, intentional viewport restore and existing Plots/Clone edits.

The genuine public HDF5 campaign covers 1K, 20K, 100K and 2M points in two series,
nonmonotone signed X, spikes/dips, 25-row NaN gaps and exact int64 identities above
2^53. The approximately 3 cm data viewport used at most 320 display points per
series while complete source bounds and selected extreme rows remained verified.
The 2M actual frame measured 4,233 ms including preparation; measured interaction
p50/p95 were 303.9/310.092 ms with an explicit extra redraw. Whole-process RSS
was 78,807,040 bytes and HWM 85,086,208 bytes. Native vector-capacity accounting
excludes allocator, string, Tcl and display-list heaps; it is not total memory or
an assertion that all internal copies were instrumented. Full canonical hashes
and source identities remained unchanged. The dense campaign was not repeated
for unchanged rendering details or other plot kinds.

Remaining Native2D axis work adds view-scoped titles, explicit intervals and
number formatting, verified physical conversions and actual raster/calibration
contexts. Axis metadata uses existing native view state, checkpoints and named
views. Dense explicit intervals thin by integral requested-step multiples;
labels retain true world anchors and do not contract scientific limits. Actual
Multiview, resize, interaction, Session restore, Python/Octave Jobs and PNG/PDF
