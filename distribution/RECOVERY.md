# Recovery and inherited limits

Extract DEV112 alongside the old installation. Keep the old Configuration and
data locations. To return to DEV111, close DEV112 and explicitly start the old
tree with its intended Configuration. Release preparation changes no owner launcher.

Migration is fresh-target-only, before demos or first startup. Failure preserves
the old installation and data; retain the private sibling logs. An API may have
partially prepared the new target before a later refusal. Do not claim that target
migrated or overwrite it silently; resolve the issue and use a new extraction.

Normal Session owners may write metadata during application use. Reverting a
framework does not undo those writes. Keep a Session recovery copy before opening
important Sessions in a new release. Release tools do not copy or rewrite RAW,
Libraries or canonical scientific payloads.

## Preserved limits

- CORE, ALWAYS, selectable, activation, dependencies, quiescence and restart
  policies are unchanged, including inherited non-Acquisition ALWAYS restrictions.
- All non-demo modules are bundled; the installer is demo-only. Independent
  registration comes only from the recorded clean preparation API transaction.
- Legacy models, instruments and Analysis definitions without package manifests
  retain accepted bundled behavior and existing lifecycle limitations.
- Existing checksum/adoption limitations remain. The owner-authorized waveform
  descriptor change updates only its module.ini checksum; no wholesale resealing.
- New containers preserve accepted payloads when exact originals are unavailable.
  Scientific/runtime source and binaries are not rewritten or rebuilt. Owner
  Curve Digitizer ZIPs remain originals.
- Native binaries retain accepted Linux ABI/runtime prerequisites. No new platform
  support or Native2D optimization is introduced.
- Historical prose may reference raw evidence retained in accepted archives;
  old campaigns are not embedded. Required current manual resources are retained.
- The Default Configuration Generator is outside scope.

Scientific limits in `../GX-TXT_REMAINING_WORK_TODO.md` remain honest: genuine
paired PerkinElmer PRF, genuine Fluorophores exports, and unqualified Andor SIF
physical calibration/2D claims remain REAL_UNVERIFIED where references are absent.

acceptance. Additional actual distribution limits appear in the final report.
