GX-TXT 0.9.8.10-dev-112-r2 — complete standalone distribution

Complete Debian 13 amd64 release: application, CORE, 149 scientific modules, optional Demos and Generators, Compute Node and graphical installer.

  • Base gxtxt package: application and 149 non-demo modules, installed under /opt/gx-txt.
  • Optional packages: 15 Demos, 39 public Generators and mTLS Compute Node with SSH setup.
  • Alternative graphical installation into a new folder and a complete public framework archive.
  • The original Curve Digitizer Viewer 2.0.26 and Preview 0.1.12 packages are preserved unchanged.

DEV112-r2 is a complete standalone release; replaying the DEV111 patch chain is not required.

GitHub replaces ~ with a dot in the downloaded .deb filename; the package bytes and internal Debian version remain unchanged.

Debian 13 amd64 only. Use APT for package installation and follow documented optional component setup. Preserve previous installations and personal data.
