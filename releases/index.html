  1. 111
    0.9.8.10-dev-111

    Viewer authoring, 100 shared icons and experimental EAGLE inspection

    LATEST IN THIS TIMELINE

    GX-TXT dev-111 revision r3 extends the scientific Viewer development environment with improved numeric-template admission, a larger shared icon catalog, paired EAGLE source inspection and additional scientific interoperability. The original earlier revision archives remain separate.

    Selected changes

    • Correct the default numeric-template Viewer initializer to request the host value/text operations used by its source.
    • Expand the Viewer Builder shared icon catalog to 100 assets in five families, with bounded catalog, preview, assignment and reversible editing workflows.
    • Introduce an experimental paired EAGLE source snapshot inspector supporting source-preserving import, inspection and Save/Open behavior; it is not a PCB, Circuit or electromagnetic solver.
    • Extend chromatography/Replicate interoperability, scientific animation/video export, incremental Curve Workbench controls and user documentation, preserving existing canonical scientific ownership.
    • Retain original Curve Digitizer 2.0.9 behavior. New manual and selected tutorial materials are released with explicit scientific limitations.
    Scientific scope

    Revision r3 includes a native HTML Viewer with known rendering limitations and seven tutorial packages still under development. The previous official plugin ZIP packages are retained; dev-108-only maintenance patches are incompatible with dev-111.

  2. 110
    0.9.8.10-dev-110

    Scientific Preview, digitization and chromatography integration

    GX-TXT dev-110 expands shared scientific Preview components, Curve Digitizer integration and chromatography acquisition tools.

    Selected changes

    • Native Preview gains additional shared components for grouping, coordinates, retained overlays and source-bound data representations; Session creation and cache ownership receive targeted corrections.
    • Original Curve Digitizer 2.0.9 is integrated without changing its scientific Quality calculations; a separate CORE source-integrity observation accompanies the update.
    • Metrohm IC Net CHW and standard AIA/ANDI chromatography acquisition modules are added with provenance, bounded file parsing and independent qualification notes.
    • Session promotion and persistence, Generate dialog geometry, Modules settings, bounded Print tables, ScriptJob duplex and Scientific Library metadata host handling receive incremental improvements.
    • The preparation guide for Curve Digitizer is expanded with graphics and published scientific calibration/provenance concepts.
    Scientific scope

    The source includes developing GUI/Octave integrations and native HTML lifecycle components. Previous official plugin packages remain unchanged; dev-108-only maintenance patches are incompatible with dev-110.

  3. 109
    0.9.8.10-dev-109

    Stable installed Viewers, scientific editing and document tools

    GX-TXT dev-109 separates restricted C++ Viewer development compilation from installed Viewer execution and extends the scientific workspace with richer Dataset tools, electronic diagrams, native CAD/electromagnetics and scientific documents.

    Selected changes

    • Installed restricted-C++ Viewers start and handle normal UI events without recompilation. Explicit author builds remain a separate supported development operation; this is the dev-109 CORE solution, NOT the dev-108-only hotfix.
    • Shared electrical diagrams gain more consistent wire junctions, terminal probing, schematic selection and engineering value controls; preserved scientific source and managed Job/provenance owners remain authoritative.
    • Curve Workbench and Dataset Preview improve dimensionality, calibrated axes, durable Session-local preview caches, large scientific labels and raw Dataset/schema inspection.
    • Scientific Print/PDF adds poster composition, and the document Viewer family extends bounded HTML, LaTeX editing/PDF production and shared source/asset publication interfaces.
    • Builder-based 3D CAD and Electromagnetics Studio viewers reuse established scientific geometry/FEM owners; Scientific Library Workspace and Modules/Script UI gain integrated presentation and controls.
    Scientific scope

    Dev-108-only hotfix.1 and hotfix.2 are incompatible with dev-109 and must not be installed or merged into it. Private scientific Sessions and internal development material are not part of the public source archive.

  4. 108
    0.9.8.10-dev-108

    Circuit Workbench and shared scientific Viewer capabilities

    GX-TXT dev-108 extends the Viewer development platform to practical electronic circuit diagrams, controlled scientific simulation workflows and native result displays, while refining Script Workspaces, numerical operations and Plot Dataset.

    Selected changes

    • Circuit Workbench 1.9.3 provides an editable native electronic diagram with named components, wires, typed properties, scientific netlist generation and managed local/remote simulation with source-aware results.

  5. 107
    0.9.8.10-dev-107

    Restricted C++ Viewer development and independent native display components

    GX-TXT expands the public Viewer architecture with a bounded C++ authoring workspace, reusable Native2D/Native3D/Plot presentation components and a more consistent Script Workspace debugger interface.

    Selected changes

    • Viewer Development API v1 integrates a restricted Clang 19 C++ subset, a fixed SDK, explicitly granted capabilities, source/project revision checks and a managed separate native worker. This does not permit arbitrary desktop code execution.
    • Native3D GUI Host v2 provides independently owned embedded Viewers with asynchronous rendering and native scene/camera interaction. Session-free Native2D and Plot v4 demonstrations remain RAM-only and do not create scientific Dataset records.
    • Python and GNU Octave Script Workspaces share a configurable pane/assistant layout with debugger call stack, variable observation, breakpoint context and exact source identity guards.
    • The Viewer Interface Builder adds integrated component examples, public UI event handling and candidate review without changing the authority of existing CORE numerical or scientific publication services.
    Scientific scope

    Restricted authoring supports C++ and grants write access only to the authorized process tree. It is not a sandbox for arbitrary hostile native code. GNU Octave asynchronous Pause is unavailable.

  6. 106
    0.9.8.10-dev-106

    Scientific Viewers, document sources and managed script debugging

    GX-TXT extends the shared scientific workspace with dedicated Signal, Statistical and HTML Viewers, richer source-document workflows and managed debugging for Python and GNU Octave. The release follows dev-104 directly; dev-105 was skipped.

    Selected changes

    • Official Signal Analysis, Statistical Analysis and HTML Viewers use public CORE services; scientific operations and GUI display retain separate authorities.
    • Markdown, HTML and structured XML can be opened with bounded source-preserving document presentation. Script execution, forms and external assets are not enabled by the HTML viewer.
    • Python and GNU Octave Script Workspaces gain shared source services, structural import, precise dirty/Undo/Redo behavior and managed debugging with stack inspection and source-revision checks.
    • Results inspection separates selectable items and independent Program output, stderr and diagnostics, with explicit source export and canonical Dataset publication.
    Scientific scope

    Advanced debugger/breakpoint combinations have limited support. Source coloring is lexical; the minimal HTML renderer does not present images or CSS layouts and does not execute scripts or forms.

  7. 104
    0.9.8.10-dev-104

    Viewer Interface Builder, organized Projects and scientific Print/PDF

    GX-TXT adds a public, visual way to design Viewer interfaces and reorganizes how scientific Projects and Sessions are navigated, while building a print-ready document workflow around canonical source data.

    Selected changes

    • Viewer Interface Builder 1.0.0 offers native design and preview, public component bindings, layout/property editing, Undo/Redo and deterministic installable Viewer packages that preserve handwritten scientific handlers.
    • Project organization gains logical Session groups, hierarchical navigation and guarded drag/drop or keyboard Cut/Paste, while keeping scientific Dataset and Workspace identities intact.
    • The main scientific Print/PDF studio composes genuine pages, original PDF/image/text resources, exact typed Dataset tables, Graphs and annotations with source-aware verification.
    • CUPS printer discovery and capabilities are asynchronous and cancellable; printing requires explicit reviewed submission and stale sources or layouts are refused.
    Scientific scope

    Printer spool status indicates queue acceptance rather than physical page delivery. Some legacy Help paths use older navigation; Native3D design components and automatic Replicate domain callbacks are outside the Builder scope.

  8. 103
    0.9.8.10-dev-103

    Remote compute nodes and a more responsive scientific workspace

    GX-TXT extends its managed scientific execution and Dataset services beyond the local process, while improving Preview preparation, Viewer discovery and the consistency of interactive scientific workspaces.

    Selected changes

    • Trusted compute-node providers use mutual TLS, per-Session authorization, verified input staging and the existing durable Script Job supervisor. Runs can be observed, cancelled and reconnected without accepting arbitrary remote shell commands.
    • Canonical Datasets can be consulted remotely through bounded typed ranges and hyperslabs with SHA-verified transport; downloading a complete local copy is a separate, explicit operation.
    • Dataset Preview prepares standard scientific representations asynchronously, offers progress and cancellation, and retains a disposable verified cache. Editing presentation settings leaves the last successful frame visible until Render.
    • The grouped catalog presents distinct scientific artwork for 30 Viewer providers, with persisted presentation availability. Shared Viewer GUI controls and Replicate/Curve Workbench dialogs reuse established CORE authorities.
    Scientific scope

    The compute-node architecture supports independent processes connected over mutual TLS; local-host and remote-machine configurations depend on the provider topology. Large Preview preparation may take time; advanced shared-covariance interval estimators are not included.

  9. 102
    0.9.8.10-dev-102

    Replicate / Consensus Curves and Worksheet 2.1

    GX-TXT adds a dedicated Viewer and a public scientific API for comparing related curves, while the scientific Worksheet becomes more capable as an interactive, scriptable workspace.

    Selected changes

    • Replicate Curve Analysis 16.0 brings repeatability, calibration-sensitivity and hierarchical studies to shared Numeric and Statistical Result Semantics services, with explicit source and physical-frame identities.
    • The Replicate / Consensus Curves Viewer presents aligned and original traces, publishes canonical results and creates Plot v4 Graph Variants without replacing the underlying observations.
    • Scientific Worksheet 2.1 gains guided Dataset binding, fill, merge, cell styles and sizes, bounded Filter Views and managed Python Script Jobs with reviewed Apply.
    • Native Preview visibility becomes a lightweight operation; a public Viewer GUI manifest coordinates existing toolbar, inspector, Workspace and History services.
    Scientific scope

    Shared-factor covariance-aware estimators and confidence/prediction intervals are not available; physical curve correspondence must be justified.

  10. 101
    0.9.8.10-dev-101

    Managed scientific execution and planar FEM

    Local scientific tools become part of the supervised Session workflow. GX-TXT can coordinate supported solver runs, retain their outputs, and connect new simulation results to the same Dataset and plotting authorities.

    Selected changes

    • Trusted scientific providers reuse Script Jobs for execution, status, cancellation, logs and controlled publication; authorized Scientific I/O preserves original source identities.
    • Electromagnetics Studio integrates Gmsh/GetDP for linear planar static 2D problems, publishing exact nodes, triangular cells and fields for native visualization.
    • Mathematics Explorer and updated Numeric expression operations support bounded, unit-aware functions and numerical root/extremum searches; native raster and 3D appearance workflows expand.
    Scientific scope

    This version is limited to supported local providers and planar static FEM; CAM is design-only. The independent Replicate scientific service was not yet supplied in dev-101.

  11. 100
    0.9.8.10-dev-100

    A scientific Worksheet and Plot Dataset v4

    GX-TXT gains a scientific spreadsheet-style working environment, designed around canonical Dataset identities rather than disconnected copies of measurement tables.

  13. 098
    0.9.8.10-dev-098

    Curve Digitizer and scientific data preview

    Extracted datasheet curves and scientific source previews move closer to the same traceable data workflow, with explicit calibration and uncertainty handling.

  14. 097
    0.9.8.10-dev-097

    Shared statistical meaning and richer numerical fitting

    New numerical services help scientific modules agree on the interpretation of results, covariance, units and provenance rather than producing isolated, inconsistent outputs.

    Selected changes

    • CORE statistical-result semantics record dimensional and covariance qualifications, supported interpretations and explicitly unavailable estimators.
    • Scientific fitting expands to correlated observations/GLS, bootstrap and profile inference, complex and surface models, plus spline alternatives.

    Scientific scope
