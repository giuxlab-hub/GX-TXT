The scientific workflow

One experiment. One connected record.

Measurements, scripts, results and observations stay in the same project context instead of becoming unrelated files across separate applications.

01 / ACQUIRE

Bring in measurements

Import instrument CSV files, tabular data, audio, images, documents and other scientific inputs.

02 / STRUCTURE

Keep scientific identity

Canonical Datasets preserve stable Variable IDs, units, metadata, source links and Session provenance.

03 / ANALYZE

Use the tools you need

Combine numerical operations, statistics, spectra, fitting and registered Python or GNU Octave scripts.

04 / EXPLORE

Interpret and reproduce

Use 2D/3D plots, interactive Viewers and saved Workspaces without losing original measurements.
