# GX-TXT - Changelog

Versioned changes to GX-TXT scientific acquisition, analysis, numerical APIs, scripting, plotting, viewers, plugins and Sessions. Entries are organized by version, with functional descriptions retained from the release history.

For current interface contracts consult the API references under [docs/api](docs/api/) and the user documentation under [docs/help](docs/help/).
