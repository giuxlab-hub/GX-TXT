Selezione degli script di Session e controlli Script Workspace

Ripristina la selezione degli script Octave registrati nella Session e i controlli dei metadati negli Script Workspace.

P003 aggiorna 15 percorsi fra sorgenti e documentazione degli script. Verificare gli SHA-256 prerequisiti ed estrarre il pacchetto nella radice del framework compatibile con GX-TXT chiuso. Conservare un backup per il ripristino.

  • Mostra in GNU Octave Analysis gli script registrati nella Session attiva.
  • Aggiorna i selettori all’apertura, cambio o modifica della Session.
  • Ripristina versione e altri controlli metadati dello Script Workspace.
  • Conserva API di Script Registry, esecuzione e documentazione esistenti.
