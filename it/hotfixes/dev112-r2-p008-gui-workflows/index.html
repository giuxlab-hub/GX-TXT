Interfaccia Viewer, Plugin Manager e Configuration

Aggiornamento cumulativo DEV112-r2 P008 con ricerca dei Viewer, miglioramenti del Plugin Manager e correzioni dell'interfaccia.

  • Configuration → Modules → Viewers: ricerca interattiva, Reset e riscontri quando non ci sono risultati.
  • Correzioni di layout, informazioni di stato, impostazioni e Page Setup utilizzando i componenti esistenti.
