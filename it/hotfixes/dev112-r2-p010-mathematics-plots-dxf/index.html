GX-TXT · DEV112-r2 P010

Mathematics Explorer, Plot e Sketch DXF

La P010 aggiorna GX-TXT con Mathematics Explorer, funzionalità Plot e l'esportazione DXF degli Sketch.

  • Mathematics Explorer: modelli, relazioni, piccoli sistemi lineari, curve e studio numerico con le API scientifiche esistenti.
  • Plot: gestione della colorbar, impostazioni Render effettive e bozze/preset di presentazione.
  • Dataset: esportazione generica attraverso le API pubbliche.
  • Sketch DXF: modulo installabile separatamente tramite Plugin Manager.
  • Mathematics 2D21: generatore e Session di esempio con cinque famiglie di valori teorici sintetici.

La P010 richiede lo stato esatto post-P009. Non è installabile direttamente sulla DEV112-r2 originale.

Verificare i checksum, utilizzare lo script apply.py abbinato all'overlay, eseguire prima --check e conservare la ricevuta per il rollback post-p009.
