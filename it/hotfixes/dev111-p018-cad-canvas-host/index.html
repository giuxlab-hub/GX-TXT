CAD Canvas Host CORE riutilizzabile

Il nuovo CAD Canvas Host Native2D permette a Curve Workbench e agli altri componenti scientifici di utilizzare interazioni di editing incorporate e condivise.

Conservare un backup esatto, estrarre DEV111-P018-PUBLIC.zip nella radice del framework compatibile e riavviare. Per il ripristino recuperare dal backup i file precedenti ed eliminare i file nuovi della P018.

  • Introduce le operazioni Create/Attach per integrare o associare un Canvas esistente al contesto CAD nativo.
  • Condivide selezione, navigazione, manipolazione nativa e ciclo di vita delle modifiche attraverso i servizi CORE.
  • Integra Curve Workbench con il nuovo host preservando geometria, presentazione e History C/C++ autorevoli.
  • Estende la pianificazione responsive di Dataset Transform mantenendo i servizi scientifici di pubblicazione.

Per GX-TXT 0.9.8.10-dev-111 r3 dopo l’intera sequenza cumulativa P001-r2–P017. Chiudere l’applicazione prima di installare.
