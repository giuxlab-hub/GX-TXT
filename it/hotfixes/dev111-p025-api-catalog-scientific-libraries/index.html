Catalogo API e librerie scientifiche

Introduce il Catalogo API nativo e la gestione pubblica delle librerie scientifiche, con provider di riferimento e integrazione nei Builder.

  • Introduce un Catalogo API nativo indicizzato con identità dei sorgenti, dichiarazioni ricercabili e riferimenti ai manuali.
  • Espone servizi pubblici del Catalogo e consultazione dalle interfacce di sviluppo Viewer.
  • Definisce le API Scientific Library Manager, la registrazione di librerie esterne e i controlli di configurazione.
  • Aggiunge provider di librerie per sorgenti JSON generiche e risorse spettroscopiche IR/NMR.
  • Integra ricerca e authoring delle librerie scientifiche in Viewer Interface Builder e Script Module Builder.
  • Conserva questa prima revisione P025 come archivio storico. P025-r2 è l'alternativa successiva da P024, non una patch da sovrapporre a P025.

Patch incrementale per GX-TXT 0.9.8.10-dev-111, dopo DEV111-P024. Istruzioni di applicazione e ripristino nell'archivio.
