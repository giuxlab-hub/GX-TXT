Attivazione corretta del provider Preview nativo

Completa la compilazione dell’adattatore Preview nativo e il suo caricamento dal worker per GX-TXT dev-111 r3.

Questa è la P005 corretta. Il pacchetto include l’adattatore Preview Linux ricompilato e il bridge verso il worker esistente. Estrarlo nella directory del framework compatibile a programma chiuso, conservando il backup dei file per il ripristino.

  • Integra il componente gxpreviewprovider.so già esistente nel normale build CMake.
  • Avvia il caricamento esplicito dell’adattatore dal worker Tcl gestito di Dataset Preview.
  • Conserva proprietà scientifica dei Dataset, registrazione, abilitazione e fallback dei provider.
  • Distribuisce soltanto i tre file corretti, senza la prima versione P005 superata.

Richiede P001, P002, P003 e P004 applicate in ordine, su GX-TXT dev-111 r3 con librerie native Linux x86_64 compatibili.
