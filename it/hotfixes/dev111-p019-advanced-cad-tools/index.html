Strumenti CAD avanzati condivisi

La P019 estende gli strumenti CAD CORE condivisi, utilizzati dal Curve Workbench e dagli altri componenti di editing nativo.

Chiudere GX-TXT e conservare il backup del framework. Estrarre DEV111-P019-PUBLIC.zip nella radice dell’installazione compatibile e riavviare. Per il ripristino recuperare i file P018 dal backup e rimuovere quelli introdotti dalla P019.

  • Unifica la gestione di costruzione, topologia, controlli geometrici, vincoli e quote mediante le API pubbliche CORE.
  • Migliora la sincronizzazione dei target durante il trascinamento vincolato e la gestione sicura di Undo.
  • Condivide marker di direzione, relazioni e controlli geometrici con il CAD Canvas Host Native2D.
  • Preserva solver nativo, presentazione C++, proprietà dei Dataset scientifici e CORE History P017.

Per GX-TXT 0.9.8.10-dev-111 revisione r3, dopo la sequenza cumulativa P001-r2–P018 applicata in ordine.
