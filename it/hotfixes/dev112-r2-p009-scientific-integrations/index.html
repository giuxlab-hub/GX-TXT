GX-TXT · DEV112-r2 P009

Integrazioni scientifiche, Plot, Guide HTML e API pubbliche

Patch cumulativa DEV112-r2 P009 con miglioramenti dei Plot 2D/3D, Guide HTML, Scientific LaTeX, Python/Octave e server MCP opzionale.

  • Viewer: associazioni controllate, ricerca dei metadati nei browser e catalogo API aggiornato.
  • Plot 2D/3D e PDF: correzioni di legende, colori, assi, griglie, esportazioni e sfondi Grid/Poster.
  • Guide HTML installabili nel Plugin Manager e accessibili tramite la documentazione del framework.
  • API pubbliche di Scientific LaTeX, Python e GNU Octave per build, gestione e debugger.
  • Pacchetto Debian opzionale GX-TXT MCP Server 0.1.0 con accesso autenticato alle API Script Bridge.

La P009 è cumulativa e si applica alla DEV112-r2 originale oppure agli stati esatti post-P005, post-P006-r5, post-P007 e post-P008.

Usare lo script apply.py del pacchetto e conservare la ricevuta per il rollback. Il server MCP si installa e configura separatamente.
