Cache di compilazione Viewer C++ e diagnostica sul terminale

Una correzione temporanea contro le ricompilazioni ripetute dei Viewer nativi, con invalidazione della cache e segnalazione delle compilazioni Clang effettive.

Problema affrontato

Nella dev-108 originale, ripetendo un comando dello stesso Viewer C++ può essere ricompilato viewer.so anche quando il progetto non è cambiato.

Comportamento previsto

  • Riutilizza un binario precedentemente compilato soltanto se coincidono tutti gli hash di progetto, sorgente, design, SDK, compilatore, policy, adapter e backend.
  • Una compilazione effettiva prova a segnalare COMPILE START e l'esito sul terminale di controllo, usando un log locale al progetto quando il terminale non è disponibile.
  • Build/Export espliciti e compilazioni del debugger non sfruttano la cache. Un nuovo progetto runtime del Viewer può legittimamente compilare una volta.

Installazione sulla dev-108 originale

Chiudere GX-TXT, annullare prima un'eventuale patch v1, estrarre lo ZIP fuori dal framework ed eseguire questi comandi dalla cartella estratta:

ROOT="$HOME/gxtxt/gxtxt_pipeline_v09810dev_108"
python3 backport.py --check "$ROOT"
python3 -m unittest -v test_patch
python3 backport.py --apply "$ROOT"

Verifica dopo il riavvio

Dopo il riavvio da terminale, ripetere un'azione invariata nello stesso Viewer. Un riutilizzo della cache non dovrebbe emettere un nuovo COMPILE START. Se il terminale non mostra messaggi, consultare il log del progetto.

tail -f "/path/to/viewer-project/derived/viewer_compilation.log"

Ripristino della dev-108 originale

Eseguire il comando ROLLBACK stampato dall'installer. L'originale è conservato in .gxtxt_patch_backups; modifiche successive al file impediscono una sovrascrittura automatica.

Compatibilità e limitazioni

  • Richiede esattamente la dev-108 originale; l'installer rifiuta altre versioni o un file bersaglio già modificato. La dev-109 e ogni revisione successiva sono incompatibili per definizione.
  • Ricevute e binari conservati nel progetto non sono autenticati crittograficamente contro manomissioni intenzionali: utilizzare questa cache solo con progetti Viewer attendibili.
