GX-TXT · DEV112-r2 P011

Run, Curve Viewer 2D/3D, Curve Fitter e MCP 0.2.0

La P011 aggiorna l'esecuzione degli script, Curve Viewer, Curve Fitter e Native3D, includendo MCP Server 0.2.0.

  • Run integra le API pubbliche con l'esecuzione e l'identità dei Job supervisionati.
  • Curve Viewer 2D/3D utilizza Plot v4 e la pubblicazione esplicita di Graph e Variant.
  • Curve Fitter presenta schede per risultati e diagnostica, History scientifica e impostazioni grafiche distinte.
  • Native3D migliora margini e leggibilità delle etichette preservando geometrie, unità e camera.
  • Il componente opzionale GX-TXT MCP Server 0.2.0 utilizza i contratti API e runtime per la compatibilità.

La P011 richiede esattamente lo stato post-P010. Non è installabile direttamente sulla DEV112-r2 originale.

Seguire lo script apply.py e la guida originale di installazione, verificare i checksum e conservare la ricevuta per il rollback post-p010.
