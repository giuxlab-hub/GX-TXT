Installatore semplificato per P001, visibilità Modules

La revisione 2 dell’installatore P001 sostituisce la procedura manuale più lunga senza modificare i sei file funzionali originali.

Estrarre lo ZIP autonomo P001-r2 fuori dal framework ed eseguire bash apply.sh /path/to/gxtxt. Per ripristinare usare bash apply.sh --rollback /path/to/gxtxt, con GX-TXT chiuso. Questa revisione non cambia il payload Tcl della P001.

  • Include senza modifiche gli archivi P001 con sei file aggiornati e relativi file di rollback.
  • Consente di verificare e applicare P001 mediante un unico comando Bash.
  • Conserva backup automatici dei file originali e comando di ripristino.
  • Mantiene il comportamento di visibilità Modules e della toolbar Analysis previsto da P001.

Per GX-TXT 0.9.8.10-dev-111 r3. Applicare P001-r2 prima di P002, P003, P004 o P005. L’installatore controlla i permessi e gli SHA-256 dei file installati originali.
