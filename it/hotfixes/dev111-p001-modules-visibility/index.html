Visibilità dei moduli in Analysis e barra dei comandi

DEV111-P001 aggiorna l’interfaccia Modules di GX-TXT dev-111 r3: la visibilità dei pannelli in Analysis è indipendente dalla selezione Run, con comandi riorganizzati e preferenze conservate nella Session.

La checkbox di visibilità mostra o nasconde il pannello del modulo abilitato in Analysis, senza decidere se il modulo possa essere eseguito. Restano separate l’attivazione, le API registrate e la selezione Run. Il nome del modulo selezionato e i comandi Script Module Builder e Reset selected module runtime sono disponibili accanto alla ricerca, con adattamento alle finestre più strette.

  • Introduce un controllo mostra/nascondi per i moduli abilitati in Analysis, indipendente dalla selezione Run.
  • Conserva le preferenze di visibilità nella configurazione della Session; le Session precedenti mantengono i pannelli visibili.
  • Dispone il nome del modulo selezionato, Script Module Builder e Reset accanto alla ricerca, adattandosi alla larghezza della finestra.
  • Mantiene invariati identità, attivazione e API registrate dei moduli.

Compatibile con GX-TXT dev-111 revisione r3. Include sei file Tcl; ROLLBACK.zip contiene i relativi originali.
