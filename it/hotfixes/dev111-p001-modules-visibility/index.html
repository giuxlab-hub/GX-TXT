Correzione introdotta

Nella dev-111 originale la checkbox Modules era associata alla selezione Run, invece che alla visibilità del pannello del modulo abilitato in Analysis.

  • La checkbox mostra o nasconde il pannello del modulo senza alterarne Run, abilitazione, API registrate e descrittori.
  • I comandi originali Script Module Builder e Reset selected module runtime e il nome del modulo selezionato restano attivi e vengono disposti accanto alla ricerca, con ritorno a capo su finestre strette.
  • La configurazione della Session conserva la nuova preferenza aggiuntiva; le vecchie Session senza la chiave continuano a mostrare i pannelli.
  • Patch e rollback includono esattamente sei file Tcl; il diff applicato a un checkout isolato produce gli stessi byte dello ZIP originale.

Compatibilità e limiti

  • Esclusivamente GX-TXT dev-111 r3 originale, commit sorgente pubblico 4daf135e49378eff1f413310bc17cf32f1928c44. Nessuna patch precedente richiesta; le revisioni successive non sono automaticamente compatibili.
  • Tutti gli otto hash SHA-256 dei sorgenti coincidono con GitHub. Il commit dell’autore Debian appartiene a un’altra cronologia Git, ma i file rilevanti hanno contenuto identico.
  • L’installatore originale richiede permessi Unix 0664 (decimale 436); un clone Git normale ha generalmente 0644 e viene rifiutato. Non aggirare i controlli.
  • I test mirati originali sono documentati, ma non sono stati eseguiti qui collaudi scientifici/GUI completi, applicazioni sul server né test Windows/macOS.
  • L’indice privato delle patch aveva ancora uno stato precedente di non consegnato; questa prerelease documenta il pacchetto depositato, non un’installazione attiva.

Installazione e rollback

Leggere APPLY.md. Chiudere GX-TXT, verificare gli hash e applicare soltanto alla dev-111 r3 originale autorizzata, con i permessi Unix richiesti. Il normale clone Git con 0644 viene rifiutato. Conservare backup, giornale della transazione e procedura ROLLBACK.
