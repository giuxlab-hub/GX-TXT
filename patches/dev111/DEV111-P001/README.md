# GX-TXT dev-111 r3 — DEV111-P001

DEV111-P001 changes Modules and Analysis visibility in GX-TXT dev-111 r3.

- Shows or hides enabled module panes in Analysis without changing their Run selection.
- Places Module Builder, Reset and the selected-module label next to module search.
- Saves visibility preferences in the Session configuration.

Files: DEV111-P001.zip (six Tcl changes) and ROLLBACK.zip (the corresponding originals).

Use APPLY.md for installation and rollback. The original installer requires the matching dev-111 r3 source files and their expected Unix permissions.
