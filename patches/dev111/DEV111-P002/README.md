# GX-TXT dev-111 r3 — DEV111-P002

DEV111-P002 adds Acquisition and Preview Components to Configuration. It requires DEV111-P001 to be applied first.

- Adds scientific previews for metadata, tables, curves, native planes and raster overlays.
- Adds Preview component integration, cache handling and fallback behavior.
- Provides a Linux x86_64 native Preview component for Tcl 8.6.

Download DEV111-P002-PUBLIC.zip. Extract it outside the GX-TXT installation and follow APPLY.md. The same installer supports rollback.
