# GX-TXT DEV111-P025 — API Catalog and Scientific Libraries

## Italiano

**DEV111-P025 — Catalogo API e librerie scientifiche**

Introduce il Catalogo API nativo e la gestione pubblica delle librerie scientifiche, con provider di riferimento e integrazione nei Builder.

### Funzionalità
- Introduce un Catalogo API nativo indicizzato con identità dei sorgenti, dichiarazioni ricercabili e riferimenti ai manuali.
- Espone servizi pubblici del Catalogo e consultazione dalle interfacce di sviluppo Viewer.
- Definisce le API Scientific Library Manager, la registrazione di librerie esterne e i controlli di configurazione.
- Aggiunge provider di librerie per sorgenti JSON generiche e risorse spettroscopiche IR/NMR.
- Integra ricerca e authoring delle librerie scientifiche in Viewer Interface Builder e Script Module Builder.
- Conserva questa prima revisione P025 come archivio storico. P025-r2 è l'alternativa successiva da P024, non una patch da sovrapporre a P025.

## English

**DEV111-P025 — API Catalog and Scientific Libraries**

Adds a native API Catalog and public Scientific Library management, together with reference-library providers and Builder integration.

### Features
- Introduces a native, indexed API Catalog with source identities, searchable declarations and documentation references.
- Exposes public API Catalog services and browsing through the Viewer development interfaces.
- Establishes Scientific Library Manager APIs, external library registration and library configuration interfaces.
- Adds reference library providers for general JSON sources and spectroscopy IR/NMR resources.
- Integrates scientific library discovery and authoring into Viewer Interface Builder and Script Module Builder.
- Distributes this original P025 package as a historical revision. P025-r2 is the later alternative replacement from P024, not an overlay onto P025.

### Distribution
Framework: `GX-TXT 0.9.8.10-dev-111`. Required predecessor: `DEV111-P024`, according to the bundled README.
