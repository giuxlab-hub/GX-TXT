# Unified Documents 1.1.0

Requires the DEV112-P004 cumulative framework for authoritative review/publication guards. The framework compatibility identity remains 0.9.8.10-dev-112.

Select a canonical PDF/image Dataset and use Open source. The bounded selector exposes the full identity in its drop-down; source status shows page, dimensions, SHA and job state. Page, DPI and Zoom remain adjacent. Recognition settings opens language, PSM and PDF-method options.

The Tools control independently hides or shows the icon palette directly above the existing preview. Hiding it retains the live image, region, current tool, pan and zoom. Hover an icon for its action; native View commands expose the same operations. Region and Pan visibly indicate the active mode. Middle-mouse pans. Escape cancels a region gesture and restores its previous region.

OCR prioritizes editable recognized text. Run OCR, Copy text and Publish text remain visible; Options opens workflow/scope/output identity. Tables similarly keeps Extract table/Publish table available, with engine/header/columns/index/output under Options. Double-click a cell, or use F2/Return on the focused cell, to edit. Enter commits and Escape cancels. Tab and Shift+Tab commit and move to the next or previous cell. Review provenance identifies retained drafts. A draft retained after a source/page change can be published only after returning to its original current source/page/SHA. Oversize text refuses commit/publication without truncation; correct the editor below the 4 MiB UTF-8 limit.

Images/PDF publication remains source-dependent. Outputs are canonical Session Datasets; original scientific sources are never changed. History, Workspace and Help use the framework owners. Save/Open preserves reviewed data and control visibility. Native File/View/OCR/Tables/Export menus and keyboard traversal expose common actions. Ctrl+O opens source, Ctrl+R renders, Ctrl+0 fits, Ctrl+Shift+R selects Region, Ctrl+Shift+P selects Pan, Ctrl+Shift+O runs OCR and Ctrl+Shift+T copies review text.

This Viewer reuses the original public CORE OCR/Table providers. It introduces no OCR algorithm or accuracy claim, private plugin dependency, Canvas, scheduler or History owner.
