# Known limits of this corrective release

## NATIVE3D_NEAR_END_ON_CAPTION

A scientific 3D axis caption can become unreadable when viewed nearly along its
axis. GUI reproduced the same Z-axis-title behavior on accepted P011 and the
corrective candidate, with identical native rendered images at the same camera.
Independent TECH/SCI source and evidence reviews confirmed the inherited behavior
and qualified the proposed mechanism; those reviews were not additional runtime
reproductions. The original native engine and binaries are
preserved; this issue is unresolved and is **not claimed fixed by P011-bis**.

The observation concerns presentation. The tested canonical source values,
geometry, units, requested camera and source identities remain unchanged. The
exact actor/raster mechanism has not been fully measured; the projected-axis
explanation is a source-supported inference, not a proven complete dynamic cause.
Choosing a different camera can improve legibility but is not a software fix.

This is an additional inherited baseline limitation. The mandatory modern GX3DE
owner integration, ordinary 3D preparation/interaction/export/publication and
persistence checks are assessed independently against the owner mandate. C12.7
requires additional defects to be recorded without falsely resolving them; it
does not expressly require this particular unchanged caption behavior to be fixed
or separately waived before the scoped cumulative correction is delivered.
No later P011-tris, engine rewrite, owner waiver or automatic follow-up release
is authorized or asserted by this disclosure. The original failure evidence and
independent instruction-scope reviews are included in the delivery evidence.

## Validation environments

GUI evidence is limited to the actual Debian/X11 environments, available local
themes and scaling settings recorded by the validators. An unavailable screen
reader, dark/high-contrast theme or other operating system is not certified by
source inspection or screenshots. These original qualifications remain explicit;
they do not imply a Windows port or unsupported UI capability.
