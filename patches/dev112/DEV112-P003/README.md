# GX-TXT DEV112-r2 P003 — Multilayer Native2D Canvas and Builder

## Italiano

**Canvas Native2D multilivello e Builder**

Estende Native2D con un Canvas multilivello e integra l'authoring nei Viewer.

- Aggiunge composizione di raster, vettori, testo e spline attraverso le API CORE esistenti.

- Include il Viewer dimostrativo originale installabile separatamente tramite Plugin Manager.
- Richiede la catena completa DEV112-r2 → P001 → P002 corretta.

**Prerequisito:** DEV112-r2 + P001 + corrected P002. Aggiornare prima DEV112-r2 a P001 e P002 corretta, poi applicare P003.

## English

**Multilayer Native2D Canvas and Builder**

Extends Native2D with a multilayer Canvas and Viewer-authoring integration.

### Features

- Adds raster, vector, text and spline composition through existing CORE APIs.
- Integrates the Canvas into Viewer Interface Builder and the restricted C++ SDK.
- Includes the original demonstration Viewer for normal Plugin Manager installation.
- Requires the full DEV112-r2 → P001 → corrected P002 predecessor chain.
