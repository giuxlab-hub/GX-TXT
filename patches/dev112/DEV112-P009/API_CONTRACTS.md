# Public API contracts

The installed original Bridge list/describe operations and
the provider's public declarations are authoritative for exact callable signatures,
typed results, activation, ownership and availability. A declared API is not a
promise that a disabled/missing provider or incompatible context can invoke it.

Current authoring uses Plot API v4, preserving historical v3 wrappers. Existing
native Plot/Variant owners retain scientific source identities, units and render
semantics. Applicable GUI controls require actual state/render evidence.

Canonical Family grouping keys remain distinct from display labels. Historical
Source consultation retains its original prepared labels, unit formatting and
resolved automatic legend placement. Current native authoring uses the captured
Dataset display-unit policy for automatic Family units, with the source unit as
its default; explicit units use the existing coordinate/Unit Registry checks.
It retains its native execution path. Frozen presentations carry semantic
metadata and preserve explicit editing priority. The metadata-only Source
export is an internal read-only projection; it does not relax the original full
preview's geometry guards or introduce a public command-execution capability.
Independent source-specific evidence retains the actual tested identity; final
installed-source/package qualification is recorded separately.

INTERACTIVE_DOCUMENT_API_v1 retains existing article/Workspace operations and
adds tex_build, tex_cancel and tex_export using original compilation, cancellation,
Resources and publication. Python and Octave use the same typed Bridge contract.
Status exposes actual managed build state, diagnostics and original log/PDF
Resources. Revision/asset guards refuse stale builds or exports.

SCRIPT_EXECUTION_API_v1 and SCRIPT_JOB_API_v1 expose the shared language-selected
contract in core/contracts/common_script_management_v1.json. They retain the two
existing editors and common Library/Registry. Existing-source mutations require
source SHA, revision, full record SHA and owner context. Projects preserve the
complete source tree and entrypoint. Jobs use immutable approved snapshots and
the original Supervisor. Real native Debug controls return actual stacks/locals;
unsupported Octave asynchronous Pause is refused explicitly.

The optional MCP generic tool is `gxtxt_bridge_call(api_id, operation, args,
approved_reference)`. Args are the original typed envelopes, not arbitrary code.
The `bridge_response` field preserves the original result/error envelope and
stable identifier. API discovery reflects all actually exported providers;
MCP adds no scientific provider allowlist. Session and explicit direct invocation
grants are required, and original owners continue to enforce their contracts.

Bulk numeric results retain original typed binary descriptors. Read only an
opaque Resource issued to the same admitted client context through the bounded
gxtxt://bridge/buffer template. Source authoring and execution additionally require
separate Author/Run grants and exact locally reviewed request/full Registry source
identity. MCP supplies no shell/eval API or arbitrary filesystem endpoint.

MCP issue reporting is provisional and redacted by default. Preview does not
persist or publish. Exact digest approval authorizes local persistence; a separate
local export action is required to copy a report. Private arguments, scientific
content, credentials, source, hostnames and raw logs are not report fields.
Reports identify actual available API/provider versions and the SHA-256 revision
of the exact public API and operation descriptors; absent values remain unknown.

Live result budgets are checked against raw response bytes before decoding or
exposure. A transport outcome that cannot be established taints its context;
mutations are not replayed. Explicit Session selection replaces unusable or
insufficient-capacity contexts while failed selections preserve a usable prior
context. Source-review Library handoff rechecks the original complete Registry
identity in the current Session before presenting the source.
