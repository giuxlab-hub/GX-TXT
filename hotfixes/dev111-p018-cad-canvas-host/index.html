Reusable CORE CAD Canvas Host

A new shared Native2D CAD Canvas Host allows Curve Workbench and other scientific consumers to use the same embedded editing interactions.

Preserve an exact backup and unzip DEV111-P018-PUBLIC.zip into the compatible framework root. Restart afterward. Restore previous files from backup and remove P018-added files for rollback.

  • Add host Create/Attach lifecycle for embedding or adopting an existing Canvas and native CAD context.
  • Share selection, navigation, native manipulation and edit lifecycle through the existing CORE services.
  • Integrate Curve Workbench with the common host while retaining authoritative C/C++ geometry, presentation and History.
  • Extend responsive Dataset Transform planning within established scientific publication services.

For GX-TXT 0.9.8.10-dev-111 r3 after the complete cumulative P001-r2 to P017 patch sequence. Close the application before installation.
