Problem addressed

Repeated restricted C++ Viewer actions in the unmodified dev-108 can rebuild viewer.so unnecessarily when the same project has not changed.

Expected behavior

  • Checks the source, design, project, SDK, compiler, adapter, policy and backend fingerprints, the build receipt and the native binary hash before reusing a project-local compiled Viewer.
  • Only when a real Clang build begins for that GUI event, displays a nonmodal Tk notice: Compilazione C++ del viewer in corso...; the notice closes on event completion, error or Viewer closure.
  • Reports COMPLETED (C++ compiled) or COMPLETED (C++ binary reused) after success. No terminal or fallback log is needed and Script Job stdout/stderr are untouched.
  • Explicit Build/Export and debugger builds use the original separate paths. A newly generated runtime project may legitimately compile once.

Install only on unmodified dev-108

Close GX-TXT. If v2 was installed, use the rollback command and verified original backup from its installer first. Do not stack patches. Extract the v3 ZIP outside the framework and run these commands in the extracted directory against an unmodified dev-108:

ROOT="$HOME/gxtxt/gxtxt_pipeline_v09810dev_108"
python3 backport.py --check "$ROOT"
python3 -m unittest -v test_patch
python3 backport.py --apply "$ROOT"

Verify after restart

Restart GX-TXT and repeat the same action with the same unchanged restricted C++ Viewer project. The first compilation can show a brief popup; later cache hits should show no popup. The final Viewer status identifies compiled or binary reused.

Restore original dev-108

Use the exact ROLLBACK command printed by the v3 installer. It restores both original files from verified backups and refuses to overwrite later edits.

Validation and security limitations

  • Strictly for the exact original GX-TXT dev-108 source, commit 6371001a219a4e611ce89c8b396c62294e6b979c. Python AND Tcl file identities are checked. All other releases, including dev-109, are incompatible by policy.
  • Hotfix.2 supersedes hotfix.1 but cannot be applied over it. Fully roll back v2 using its verified original backup, or restore a pristine dev-108 installation; do not force overwrite.
  • Six isolated tests passed, including Tcl polling and marker lifecycle. No actual complete Debian GX-TXT GUI and Clang acceptance was performed during this publication.
  • Project-local build receipts are not an adversarial tamper-proof binary trust guarantee; use only trusted authored Viewer projects.
