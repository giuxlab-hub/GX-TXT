Patch available · DEV111-P022

Native3D rendering and Sketch lifecycle

Updates the Native3D rendering pipeline, camera input, CAD projection and persistent Sketch display.

  • Improve explicit Hardware renderer-process initialization and device diagnostics for the supported NVIDIA 390 path.
  • Batch queued camera operations while retaining the order of input events.
  • Reduce intermediate PNG transport cost in common GUI drawing paths.
  • Reuse native coordinate transformations and prepared CAD geometry for projected Sketch presentation.
  • Handle temporarily unmappable camera orientations without altering Sketch data.
  • Keep saved Sketch geometry visible after editor Close, with subsequent reopening of the same Document and History.

Cumulative GX-TXT 0.9.8.10-dev-111 r3 update after DEV111-P021. Consult the packaged instructions for application and rollback details.
