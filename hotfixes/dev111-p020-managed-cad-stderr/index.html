Managed CAD Sketch and STDERR Diagnostics

Shared CAD Sketch tools, public Viewer commands and optional managed-process STDERR collection.

  • Create, open and close managed Sketches on oriented 3D workplanes, associated with scientific Documents.
  • Edit geometry, constraints, dimensions and defining controls with native CAD tools, Undo/Redo and persistent CORE History.
  • Expose a common public CAD action catalog to Viewer menus, toolbars, palettes and Canvas controls.
  • Provide the Test CAD 1 and Test CAD 2 reference Viewers using public Builder and C++ development interfaces.
  • Collect optional process STDERR through bounded asynchronous services, rotating JSONL logs, configuration and a dedicated Diagnostics Viewer.
