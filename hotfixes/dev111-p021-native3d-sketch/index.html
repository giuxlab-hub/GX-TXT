CAD Sketch editing inside Native3D

Sketch editing occurs in the existing 3D viewport, together with the scene, solids and Navigation Cube.

  • Draw and modify Sketch geometry directly on the active workplane in the existing Native3D viewport.
  • Display a transparent retained CAD overlay with grid, handles, curve outlines, constraints, dimensions and snapping.
  • Map pointer and camera interactions between Sketch-plane coordinates and the 3D world.
  • Use shared CAD commands, Finish/Cancel, Undo/Redo and persistent Documents without a competing CAD controller.
  • Integrate Scientific 3D Workbench, reference CAD Viewers and Hardware/Software/Auto rendering selection.
