Shared advanced CAD tools

P019 extends the shared CORE CAD tooling for Curve Workbench and other native editing consumers.

Close GX-TXT and back up the installed framework. Extract DEV111-P019-PUBLIC.zip into the compatible framework root and restart. To roll back, restore the original P018 files from backup and remove new P019 files.

  • Unify construction, topology, defining-control, constraint and dimension editing through public CORE CAD tools.
  • Improve constrained-drag target synchronization and safe Undo admission during geometry editing.
  • Share direction-marker, relationship and geometric-control workflows with the embedded Native2D Canvas Host.
  • Preserve the existing native solver, C++ presentation, scientific Dataset ownership and P017 CORE History.

For GX-TXT 0.9.8.10-dev-111 revision r3, after P001-r2 through P018 applied cumulatively and in order.
