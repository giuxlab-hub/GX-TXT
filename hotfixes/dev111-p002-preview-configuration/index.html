What the patch changes

The original Configuration did not expose the new dedicated Acquisition/Preview Components presentation and bounded registered native Preview extension workflow.

  • Add dedicated Acquisition and Preview Components tabs to the existing Configuration interface while preserving existing exporter, Viewer, and module management.
  • Present registered provider results as metadata, tables, scientific curves, bounded native planes, and raster overlays under canonical Dataset, Session and Preview controls.
  • Retain the existing scientific source identity, provider activation, cache invalidation, fallback behavior, and a fixed C-gated native worker without uncontrolled GUI authority.
  • The original P002 patch provides 18 science/source payload files, with 15 exact original-file preimages for rollback and three controlled new files.

Compatibility and limitations

  • Only GX-TXT dev-111 revision r3, with DEV111-P001 applied first. This is the second sequential patch, not a replacement for P001 and not a patch for later framework versions.
  • The installer verifies all six previous P001 postimages, unchanged original native engine and the exact 18 P002 file conditions. Any mismatch stops the operation.
  • The native addon is Linux x86_64 and Tcl 8.6 specific; other operating systems or incompatible ABIs are not supported.
  • The public distribution excludes private test captures and machine paths. Its scientific payload, original installer, manifest and rollback preimages are byte-identical to the verified deposit.

Installation and rollback

Close GX-TXT, extract the distribution ZIP and follow APPLY.md. Run bash apply.sh /path/to/gxtxt after P001 is present. Use bash apply.sh --rollback /path/to/gxtxt to restore the post-P001 state. Never bypass version or SHA-256 guards.
