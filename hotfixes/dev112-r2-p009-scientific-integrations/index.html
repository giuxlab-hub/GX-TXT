GX-TXT · DEV112-r2 P009

Scientific Integrations, Plot, HTML Guides and Public APIs

Cumulative DEV112-r2 P009 update improving 2D/3D Plots, HTML Guides, Scientific LaTeX, Python/Octave and the optional MCP server.

  • Viewers: validated associations, metadata search in existing browsers and API Catalog refresh.
  • 2D/3D Plot and PDF: improvements to legends, colours, axes, grids, exports and Grid/Poster backgrounds.
  • Installable HTML Guides managed through Plugin Manager and the framework's documentation facilities.
  • Public Scientific LaTeX, Python and GNU Octave APIs for build, management and debugging.
  • Optional GX-TXT MCP Server 0.1.0 Debian component with authenticated Script Bridge API access.

P009 is cumulative and applies to the original DEV112-r2 or exact post-P005, post-P006-r5, post-P007 and post-P008 states.

Use the provided apply.py and retain the installation receipt for rollback. The MCP server is installed and configured separately.
