P011-bis — Curve Viewer and Scientific Workflow Corrections

Corrective update for P011 with GX3DE integration, Curve Viewer and Curve Fitter improvements and Script Bridge fixes.

  • Curve Viewer and Plot v4: Native3D via the modern GX3DE engine, export, publication and Workspace handling.
  • Curve Viewer: guided selection, existing typed colour controls, compact dialogs, filters and draggable legend.
  • Curve Fitter: parameter labels/units, style preservation, display aspect and actual solver status.
  • Python, Octave and Jobs: retained source identity, typed errors/results and resource tracking.
  • Independently accepted GUI/TECH/SCI delivery with an atomic installer and receipt-based rollback.

Prerequisite: P011-bis requires the exact P011 installation and does not apply to earlier baselines. Download the complete TAR.GZ and follow patch/atomic/INSTALL.md; do not use a detached installer script.

Inherited limitation: a Native3D axis caption may become unreadable at a nearly end-on camera angle. This issue is not claimed fixed.
