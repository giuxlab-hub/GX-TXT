GX-TXT · DEV112-r2 P010

Mathematics Explorer, Plot and Sketch DXF

P010 updates GX-TXT with Mathematics Explorer, Plot improvements and Sketch DXF export.

  • Mathematics Explorer: models, relations, small linear systems, curves and numerical study through existing scientific APIs.
  • Plot: colourbar precedence, effective Render settings, presentation drafts and presets.
  • Dataset: generic export through public APIs.
  • Sketch DXF: independently installable module through Plugin Manager.
  • Mathematics 2D21: generator and sample Session with five families of synthetic theoretical values.

P010 requires the exact post-P009 state. It does not install directly on the original DEV112-r2 base.

Verify checksums, use apply.py paired with the overlay, run --check first and retain the receipt for post-p009 rollback.
