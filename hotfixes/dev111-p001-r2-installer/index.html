Simplified installer for P001 Modules visibility patch

P001 installer revision 2 replaces the longer manual installation procedure without changing the six original functional source files.

Extract the self-contained P001-r2 ZIP to a separate folder and run bash apply.sh /path/to/gxtxt. Roll back with bash apply.sh --rollback /path/to/gxtxt, with GX-TXT closed. This installer revision does not change the P001 Tcl patch payload.

  • Provide the original P001 six-file update and rollback archives unchanged.
  • Use one Bash installer command to check source identity and apply P001.
  • Preserve automatic original-file backups and the rollback command.
  • Maintain the same Modules visibility and Analysis toolbar behavior as P001.

For GX-TXT 0.9.8.10-dev-111 r3. Apply P001-r2 before P002, P003, P004 or P005. The installer checks the original installed file modes and SHA-256 identities.
