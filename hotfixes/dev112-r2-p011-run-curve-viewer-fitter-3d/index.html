GX-TXT · DEV112-r2 P011

Run, Curve Viewer 2D/3D, Curve Fitter and MCP 0.2.0

P011 improves script execution, Curve Viewer, Curve Fitter and Native3D and includes MCP Server 0.2.0.

  • Run connects public APIs to supervised Job execution and admission.
  • Curve Viewer 2D/3D uses Plot v4 and explicit Graph/Variant publication.
  • Curve Fitter provides result and diagnostics tabs, scientific History and separate presentation settings.
  • Native3D improves margins and label legibility while preserving geometry, units and camera.
  • The optional GX-TXT MCP Server 0.2.0 uses actual public API/runtime contracts for compatibility.

P011 requires the exact post-P010 state. It does not install directly on the original DEV112-r2 base.

Follow the original apply.py and installation guide, verify checksums and retain the receipt for post-p010 rollback.
