What the patch changes

In the original dev-111 Modules page, checkbox state was tied to Run selection instead of controlling whether enabled module panes were shown in Analysis.

  • Checkbox toggles the module pane in Analysis without changing its separate Run selection, enabled state, registered API capability or module descriptors.
  • The original Script Module Builder, Reset selected module runtime and selected-module label remain functional and are repositioned beside Modules search, wrapping at narrower widths.
  • Session Save Config preserves the additive visibility preference; older Sessions without the new key retain the existing visible panes.
  • Patch and rollback each contain exactly six Tcl files, and an isolated Git diff reproduces the original patch byte for byte.

Compatibility and limitations

  • Only original GX-TXT dev-111 revision r3, exact public source baseline commit 4daf135e49378eff1f413310bc17cf32f1928c44. No predecessor patch is required; future revisions are not automatically compatible.
  • All eight baseline source SHA-256 checks match the public commit. The original Debian author Git SHA differs only in repository history, not in the pinned source content.
  • The original apply procedure requires Unix mode 0664 (decimal 436). An ordinary Git checkout typically has mode 0644 and will be refused. Do not bypass mode or checksum guards.
  • Focused author test evidence was reviewed, but full scientific/GUI regression, live application/installation and Windows/macOS platform checks were not performed during this publication.
  • The private upstream patch-series index still carried an earlier not-delivered status; this GitHub prerelease documents the deposited focused-tested patch, not an active installation.

Installation and rollback

Read the reviewed APPLY.md. Close GX-TXT, verify both ZIPs and source hashes and apply only to an authorized original r3 installation with required Unix permissions. Original installer refuses a normal Git clone with mode 0644. Preserve transaction preimages and the exact ROLLBACK procedure.
