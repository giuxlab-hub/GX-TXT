Modules panel visibility and Analysis toolbar

DEV111-P001 updates the Modules interface in GX-TXT dev-111 r3: module visibility in Analysis is controlled independently of the Run selection, with reorganized toolbar actions and Session persistence.

Updated P001-r2 installer ↗

The visibility checkbox affects the enabled module panel shown in Analysis, not whether that module is available for execution. Existing module activation, registered APIs and Run choices remain separate. The selected-module indicator, Script Module Builder and Reset selected module runtime commands remain accessible alongside the module search, with wrapping at narrow window widths.

  • Add a separate show/hide control for enabled modules in Analysis without modifying the Run selection.
  • Store each module’s visibility preference through existing Session/configuration persistence; existing Sessions without that preference retain visible panels.
  • Arrange the selected-module label, Script Module Builder and Reset commands alongside search, adapting to window width.
  • Keep existing module identity, activation and API registration behavior unchanged.

Compatible with GX-TXT dev-111 revision r3. Six Tcl files are included; ROLLBACK.zip contains the corresponding original files.
