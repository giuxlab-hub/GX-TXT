Native resident 3D Sketches (EXP01)

Experimental cumulative release with resident Sketch geometry, native depth, multi-plane scenes and fast Document admission.

  • Keep derived Sketch curves as native resident display actors in the existing Native3D scene.
  • Present multiple Sketch workplanes together with 3D meshes and native depth occlusion.
  • Pick resident Sketch curves to open their originating scientific Document for exact editing.
  • Preserve Native2D geometry, constraints and CORE History, with existing grid and editing controls.
  • Introduce bounded Document caches and quick-open descriptors for faster listing and scene admission.
  • Batch native actor admission and reuse Scientific 3D Workbench, Tcl/C++ interfaces and the Navigation Cube.

Cumulative GX-TXT 0.9.8.10-dev-111 r3 update after DEV111-P022. Consult the packaged instructions for application and rollback details.
