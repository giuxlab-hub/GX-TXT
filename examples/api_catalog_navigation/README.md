# Private API Catalog navigation test Viewer

This is a validation/example fixture, not an installed bundled Viewer. Open
`navigation.gxtxt-viewer` in the real Viewer Interface Builder. Its four nested
tabs cover a source-neutral public reference, Python, Octave and C++ SDK views.
The `generated/` sources are produced by the ordinary public Viewer generator;
`packages/` holds the exact generated test-scoped Plugin Manager ZIP and checksum.

Use a fresh private test framework/configuration to install and open that ZIP
normally for independent GUI acceptance. No owner installation is modified.
The design, generated connector and component contain no scientific handlers.
The component has no refresh/rebuild GUI control. Existing editor reload buttons
remain indexed-view reloads only. Catalog maintenance is the public programmatic
API plus automatic startup/plugin lifecycle reconciliation.

Native index queries, exact declaration details, selected references, manuals,
keyboard/scrolling and bounded paging use the same CORE component as the three
editors. Builder save/open/Generate Viewer preserves the declaration. Viewer
capture/restore retains presentation state without caching grants or handles.
