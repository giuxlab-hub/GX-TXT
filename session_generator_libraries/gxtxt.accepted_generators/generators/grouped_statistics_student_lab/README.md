# Grouped Statistics Student Lab

This Session Generator creates a deterministic GX-TXT Session for learning `analysis.statistics.grouped`.

The default exercise groups measurements by `site`, analyzes voltage/current variables inside a preconfigured Selection, omits one missing group value and non-finite measurement values explicitly, and creates persistent mean/SEM, median/IQR, and group-count `plot.dataset` variants.

After generation, read `STUDENT_GUIDE.txt` inside the Session.
