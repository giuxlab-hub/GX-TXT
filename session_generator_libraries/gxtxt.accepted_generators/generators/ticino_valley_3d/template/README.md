# Ticino Valley 3D Cartography generated Session

This Session was generated by `GX-TXT Geospatial Examples / Environmental / Cartography / Ticino Valley 3D Cartography`.

Import the four CSV files in `raw/` as four normal `table.generic` Datasets, using the Dataset IDs documented below:

- `ticino_valley_grid` -> `raw/ticino_valley_grid.csv`
- `ticino_valley_settlements` -> `raw/ticino_valley_settlements.csv`
- `ticino_river_centerline` -> `raw/ticino_river_centerline.csv`
- `ticino_hydraulic_demo` -> `raw/ticino_hydraulic_demo.csv`

After each Dataset import, open Variables -> Metadata... -> Import..., select the matching `metadata/<dataset>.metadata.txt`, review it, then Save. Metadata are recommended but the analysis plugin is designed to remain functional when they are absent.

`metadata/ticino_valley.metadata.txt` is a shared human/portable summary. The four dataset-specific files already repeat the required common keys, so it is not necessary to import the shared summary separately.

See `reference/SOURCES.md` before interpreting the data. Cartographic layers are derived from real public sources; the hydraulic field is explicitly synthetic.
