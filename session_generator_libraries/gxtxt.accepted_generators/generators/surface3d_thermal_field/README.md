# 3D Thermal Surface Session Generator

Generator ID: `surface3d_thermal_field`  
Version: `1.0.0`

Import this package into the existing **GX-TXT Numerical Examples** Session Generator Library. It creates the deterministic 41 × 41 thermal-surface fixture used by `demo.visualization.surface3d`.

Generated files:

- `raw/thermal_surface_3d.csv`
- `metadata/thermal_surface_3d.metadata.txt`
- `reference/thermal_surface_truth.txt`

The field contains two Gaussian hotspots and a weak linear gradient. No random noise is used.
