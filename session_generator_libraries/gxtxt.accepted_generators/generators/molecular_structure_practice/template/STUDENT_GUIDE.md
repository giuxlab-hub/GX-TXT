# Molecular structure practice

This Session contains two unchanged CC0-1.0 wwPDB Chemical Component Dictionary ideal-coordinate sources: water (HOH, 3 atoms and 2 bonds) and tyrosine (TYR, 24 atoms and 24 bonds). Coordinates are in ångström. Exact source URLs, rights and SHA-256 values are in `reference/molecular_sources.json`. These are software inspection examples, not newly measured structures or a claim of physical accuracy. Each file contains one molecular record; the two molecules are not conformers of one another.

1. Generate this Session through **Generate Session → GX-TXT Accepted Session Generators → Chemistry / Molecular Structure → Molecular Structure Practice**. The framework records actual library/generator/version provenance in `metadata/session_generator.ini`. No canonical molecule or rendered scene exists until you import a source normally.
2. Open the ordinary **Molecule Viewer** from Viewers. In **Library & import**, choose the existing local SDF/MOL, XYZ or PDB import route and select this Session's `raw/HOH_ideal.sdf`. Use **Import**. The existing molecule acquisition provider owns the resulting canonical Dataset and its stable ID. Record the actual resulting ID; do not rename it or convert the molecule into a numeric XYZ table.
3. Activate that canonical molecular Dataset in the normal Dataset browser. Inspect the original-source identity, molecular contract, units and Preview. Use the normal **Open in Molecule Viewer** route and its **Open 3D structure** action to consult the same canonical source. Compare the reported 3 atoms and 2 bonds with the reference. A visible frame alone does not prove coordinate fidelity; retain the public Dataset/source receipts.
4. Save through the existing Viewer controls, close and reopen the Session normally, then select the same canonical Dataset again. Confirm that source hashes, atom/bond identities and units are retained. The generator does not pre-author this saved presentation.
5. Import `raw/TYR_ideal.sdf` separately if a second supported molecular source is needed. Its 24 atoms and 24 bonds belong to a different molecule. Do not concatenate these two sources to fabricate a conformer test.

Prior validated molecular navigation, malformed-input and genuine same-molecule conformer evidence can be reused at its recorded scope. This source-only generator does not replace those requirements or imply whole-Viewer or release acceptance. Use no scientific solver, new renderer or alternate source parser for this exercise.
