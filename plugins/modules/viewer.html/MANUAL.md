# HTML Document Viewer

Open a registered HTML Dataset with Open Dataset. CORE renders headings, paragraphs,
links, tables, lists and preformatted code with its bounded native C presentation
engine. JavaScript, forms, external resources and CSS are inactive; images are
omitted. This is a minimal document viewer. Original source bytes remain unchanged.
The public `HTML_VIEWER_API_v1` render operation remains available when GUI
presentation is disabled. Use the shared Code Viewer for source inspection.
