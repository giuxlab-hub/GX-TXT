# Scientific Curve Dataset Publisher 1.0.0

SPDX-License-Identifier: GPL-3.0-or-later

Independent GX-TXT export/utility extension. Curve Viewer → **Publish Dataset…**
uses one selected, visible exact Curve Source. CORE owns filtering, row order,
source validation, typed data and atomic create-only Dataset publication.
The extension does not read display points or mutate the source Workspace.
Requires public Curve Source continuity support in the installed framework.
See [MANUAL.md](MANUAL.md) for GUI/API use and provenance.
