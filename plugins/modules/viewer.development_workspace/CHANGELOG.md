# Changes

## 1.0.0

Restricted C++ source projects use the shared CORE source editor, actual Clang
lexer/AST validation, fixed curated SDK/toolchain, project-write grant and a
separate bounded native worker. GUI and CLI share one backend. Public API
inspection distinguishes installed facilities from the authorized SDK subset.
Export creates an ordinary Viewer package candidate for Plugin Manager review.
Python authoring is disabled.
