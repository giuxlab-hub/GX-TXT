# Restricted C++ synthetic temperature Viewer

Copy these three files into a new writable project directory. Open that directory
with Viewer Development Workspace, or use the installed `core/bin/gxtxt-viewer-dev`
CLI. Validate, Build, Demo, Test and Export candidate share one backend. No Session
or scientific Dataset is required. The SDK is provided automatically; author
includes and standard-library math/I/O are unavailable.

The Open handler mounts an explicit public native RAM demo. Invoke converts a
Celsius value using public NUMERIC_API_v1 array_binary.add with 273.15. The expected
value for 18 is 291.15. This is presentation-only content, not scientific publication.
The Native3D example also handles the numeric field's Changed event.

`project.json` declares the exact requested public API versions/operations and
the independently checkable event test sequence. Export only creates a candidate;
review it and use normal Plugin Manager promotion to install it.
