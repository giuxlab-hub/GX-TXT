# Scientific Spectral Library Viewer

The toolbar provides **Install library...**. Choose an independently packaged IR scientific-library ZIP. The Viewer calls CORE Scientific Library Manager API v1, which verifies the package and registers it through the IR Library Type Provider before the spectra appear in the library chooser. The four curated reference collections are separate data-only packages; no reference data is embedded in the framework. Managed-library updates and removals use the manager API. Existing user-authored Scientific Reference Libraries remain visible and are preserved; a managed package cannot silently replace one with the same ID.

Reference libraries can be browsed without an open Session; Session spectrum and IR-ranking controls become useful when one is open.

Open the Viewer from GX-TXT's Viewers tab. Select any installed Scientific Reference Library, search material/spectrum metadata, and select up to four native spectra. Their original irregular grids are retained in storage; the canvas presents them without rewriting references. Comparison choices are overlay, true Top / Bottom, stacked, difference and ratio. Overlay requires matching X/intensity semantics and explicitly shape-normalizes each trace to [0, 1]; Top / Bottom keeps native independent Y scales and synchronizes the X viewport. A Session spectrum (raw or processed) is selected by stable Dataset/variable IDs. The Viewer also reads a candidate-ranking Dataset published by `analysis.spectroscopy.ir`, allowing a ranked result to select its actual stored reference spectrum. Cursor readout, X-range zoom and pan support band inspection.

Session-specific selection and viewport are stored through the public Interactive Document API. Reference libraries themselves remain outside Sessions. The Viewer does not score or identify compounds; its difference/ratio display uses public numerical resampling, while matching remains in the Analysis module. A similarity score is not a probability.

The toolbar's **Import spectra...** button opens the user-owned library import workflow. Add one or more CSV/JCAMP-DX files, or a directory of them. Each file has independent Spectrum ID, entity/material metadata, CSV column selection, X/Y units and intensity representation, plus a numerical trace preview; JCAMP metadata may be detected when interpretation fields are left blank. Select an existing user-owned destination library or enter a new library ID, name, version and license/rights classification. Import status is shown per file and successful spectra immediately appear in the Viewer. Source files are read-only; imported data and provenance live in the persistent library, not the Session.

Within that import dialog, **Check / install TUM RefIMP...** remains a legacy user-owned source workflow. It downloads into a user-owned staging directory, verifies the audited 2022 source hash, and creates a Scientific Reference Library through the legacy reference API. Use **Install library...** for the separately packaged managed collection. If a legacy library already uses the same ID, remove or rename it deliberately before installing the managed package; neither path overwrites it silently. No entire NIST, SDBS or OpenSpecy collection is mirrored automatically.

Select exactly one reference and use **Update / remove reference...** in the right pane to maintain a library. Every action creates a new user-owned library version and preserves the selected source/version/hash. **Fork library** first when a public-source reference must eventually be removed: CORE only permits removal from a user-owned source. **Update reference** can change display metadata or parse a replacement CSV/JCAMP with the same spectral kind, axis units and ordinate representation; a provenance note is required. The dialog previews source identity, owner and content hash and reviews the destination ID/version before committing. **Remove reference** creates a further version without the selected spectrum. The resulting library is immediately selected in the Viewer; original libraries are never overwritten.
