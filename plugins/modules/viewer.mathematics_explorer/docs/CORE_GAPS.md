# Public mathematical ownership and limits

- Safe vector expressions: public Numeric expression evaluator, shared CORE
  grammar, actual registered pointwise functions and strict Unit Registry rules.
- Roots/intersections/local extrema: bounded Numeric expression analyzer using
  the existing root and minimization methods, with explicit numerical limits.
- Dimensions: existing public `expression_dimensions` and Unit Registry;
  no Viewer-owned conversion table or inferred physical meaning.
- Persistent interactive2D: accepted public native Plot Dataset widget and
  existing Graph, Dataset, Document and Session authorities.

The GUI preserves its small function grammar and32–1201-point domain sampling.
The public mathematical service supports bounded canonical Dataset inputs
without adding experimental Dataset overlay to this independent GUI. A finite
grid does not establish all roots or a globally optimal extremum. Unsupported
symbolic calculus, arbitrary expressions, out-of-plane geometry or uncertainty
models remain unavailable; no such capability is implied by a plotted curve.
