# Mathematics Explorer

An optional scientific Viewer for three real functions, explicit physical units,
public numerical analysis and interactive native graphs. Calculations use
`NUMERIC_API_v1`; graph geometry and gestures use `PLOT_DATASET_API_v4`. Session
Documents and canonical publication remain owned by CORE.

Read the complete [user guide](docs/USER_GUIDE.md), [architecture](docs/ARCHITECTURE.md)
and [public expression reference](../math.numeric/NUMERIC_EXPRESSION_OPERATIONS.md).
Original-source provenance and integration evidence are separate from functional
instructions in [integration provenance](docs/INTEGRATION_PROVENANCE.md).
