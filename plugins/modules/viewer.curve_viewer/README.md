# viewer.curve_viewer 0.2.0

SPDX-License-Identifier: GPL-3.0-or-later

Read-only 2D scientific Dataset curves with semantic family members, non-destructive filters and named Session Workspaces. Exact scientific publication is supplied by the independent export.curve_dataset extension.

See [MANUAL.md](MANUAL.md), [CHANGELOG.md](CHANGELOG.md). Install this normal module package through
the existing Plugin Manager; dependencies and public API entrypoints are declared
in module.ini.
