# Sketch Dataset Import

Import `.gxsketch` through the standard source acquisition workflow. The CORE
validates exact geometric definitions and relationships. Scientific source files
are never imported. Open Dataset starts Curve Workbench; publishing a new Sketch
and committing an explicitly authorized existing Dataset are separate operations.
See `docs/api/SKETCH_DATASET_API_v1.md` and `docs/DEV070_USER_GUIDE.md`.
