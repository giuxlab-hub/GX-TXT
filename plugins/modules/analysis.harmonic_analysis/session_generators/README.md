# Bundled Session Generator

`gxtxt_numerical_examples_harmonic_analysis_1.0.0.zip` is a portable GX-TXT Session Generator for the established **GX-TXT Numerical Examples** library.

Generator ID: `harmonic_analysis`  
Category: `Signal Processing`  
Suggested Session: `harmonic-analysis-example`

It creates a deterministic coherent multi-harmonic waveform, analytical ground truth, and a student exercise covering CSV import, FFT Spectrum, and Harmonic Analysis. Import the generator through the normal Session Generator Library UI/API; do not unpack it into a Session manually.
