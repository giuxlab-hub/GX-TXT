# Sardinia Levoglucosan Campaign Demo

`demo.environmental.levoglucosan_campaign` 1.3.0 is an external scientific demonstration plugin for GX-TXT.

Reusable regression, smoothing and summary statistics use the runtime-advertised public `math.numeric` API; the campaign's site, fire and quality-control rules remain in this module. Its fourteen graphs use persistent public Plot.dataset variants.

It analyzes the deterministic synthetic one-year Sardinia levoglucosan campaign generated by the bundled Session Generator:

```text
Library:   GX-TXT Numerical Examples
Category:  Environmental Chemistry
Generator: Sardinia Levoglucosan Campaign
ID:        sardinia_levoglucosan_campaign
Version:   1.1.1
```

The generated Session is ready to run. It already contains the canonical source Dataset, Variable Schema v3, Dataset Metadata, primary Analysis Source, module selection, and stable variable bindings. No manual CSV import, metadata import, schema editing, or binding is required.

## Configurable output groups

The module provides one analysis entry point with independently selectable output groups:

- Campaign summary
- Seasonality
- Wildfire events and fire relationships
- Measurement uncertainty and QC
- Cross-site relationships and short-lag correlations
- Robust anomaly detection
- Spatial analysis
- Automatic 2D graphs
- 3D spatial views

All groups are enabled by default. The numerical derived Datasets are always republished from the current source Dataset so disabling a presentation group does not leave stale scientific tables.

## Graphical outputs

Up to twelve 2D graphs are generated through the public `PLOT_DATASET_API_v2` path. The selected graph groups can be disabled independently through the module configuration.

Two optional 3D PNG views use persistent public `plot.dataset.xyz` variants:

- `13_spatial_3d_topography.png`: longitude/latitude/elevation geometry, colored by annual mean levoglucosan.
- `14_spatial_3d_fire_surface.png`: longitude/latitude geometry, wildfire-period mean concentration as Z, colored by wildfire enhancement factor.

The second view uses Delaunay triangles only as descriptive connectivity between the four monitoring sites. It does not claim scientific spatial interpolation.

## Main scientific outputs

The module publishes daily, monthly, seasonal and site summaries plus fire relationships, weighted regression products, uncertainty/QC tables, synchronized and lagged cross-site relationships, and robust anomaly scores. It also writes:

```text
levoglucosan_campaign_report.txt
levoglucosan_campaign_metrics.ini
automatic_graphs.ini
analysis_outputs.ini
```

The source and generated observations are synthetic and are explicitly marked as such in Dataset Metadata.

See `MANUAL.md` for the complete workflow, output definitions, scientific assumptions, literature basis, configuration options, and validation status.

## Statistical interpretation in 1.3.0

Daily, monthly, seasonal and annual summaries now retain the public CORE
statistical table, stable row identities, units and conditional assumptions in
every derived or plotting Dataset. Numeric supplies each mean, SD, SEM and exact
Student-t quantile once. Reported confidence limits are the untruncated interval;
the earlier lower-limit clipping and private t approximation are removed.
Canonical Dataset and variable IDs are unchanged. Original Sessions and earlier
release artifacts are not rewritten; rerunning explicitly updates this module's
owned derived outputs as before.

Daily intervals assume independent Gaussian technical errors. Monthly, seasonal
and annual teaching intervals additionally assume independent daily observations;
seasonal/fire structure can violate that assumption. No empirical coverage or
causal claim is made. Graph labels identify these conditional intervals.

Correlations use the public Pearson estimator directly, with CORE zero-variance
semantics. Fire regressions use relative SEM-derived weights, not known absolute
sigma. The descriptive anomaly score retains the earlier normalization
`max(1.4826 * raw MAD, 1e-9)` and QC retains `100 * SD / max(mean, 1e-12)`; these
are teaching conventions without a probability or universal acceptance claim.
MAD and arithmetic are performed through Numeric. CORE records preserve median
and MAD meaning, units and the raw scaling convention.
