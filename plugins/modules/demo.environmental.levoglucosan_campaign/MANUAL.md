## 1. Purpose

This external GX-TXT demonstration analyzes a deterministic synthetic one-year atmospheric levoglucosan campaign in Sardinia, Italy.

The scientific scenario combines:

```text
daily PM aerosol sampling
+
aqueous filter extraction
+
ion chromatography / HPAEC-PAD determination
+
levoglucosan as a biomass-burning marker
+
four Sardinian reference areas
+
three technical IC replicates per daily sample
+
winter residential biomass-burning signal
+
low ordinary summer background
+
episodic summer wildfire signals
+
measurement uncertainty
+
temporal, analytical and geographical comparisons
```

All campaign measurements generated by this package are synthetic. They are not observations from a real monitoring campaign. The generated Dataset Metadata records:

```text
data.synthetic=true
```

The literature described later in this manual is used only to choose scientifically plausible orders of magnitude and behavior.

## 4. Generated campaign

The synthetic campaign uses calendar year 2025 as a deterministic non-leap-year model:

```text
365 days
×
4 monitoring sites
×
3 technical IC replicates
=
4380 analytical rows
```

The year is part of the model. It does not imply that the synthetic measurements actually occurred in 2025.

### 4.1 Monitoring reference areas

The four synthetic monitoring reference locations represent distinct Sardinian settings:

1. Cagliari metropolitan / coastal area — urban coastal;
2. Gonnostramatza / Marmilla — rural inland;
3. Nuoro / Barbagia — mountain inland;
4. Olbia / Gallura — north-eastern coastal.

The Dataset carries site ID, name, zone, WGS84 latitude/longitude, elevation and environment class. These are reference locations for the synthetic demonstration, not claims about official monitoring stations.

### 4.2 Generator files

The generated Session includes at least:

```text

raw/fire_events.csv

datasets/demo.environmental.levoglucosan.source.csv

metadata/datasets.ini
metadata/datasets/demo.environmental.levoglucosan.source.ini
metadata/manifest.ini
metadata/campaign.metadata.txt

reference/synthetic_truth.csv
```

`raw/sardinia_levoglucosan_ic.csv` is human-readable source material. The registered canonical Dataset under `datasets/` is the source used by the ready-to-run Analysis Source.

`reference/synthetic_truth.csv` exists only for generator/test validation. The normal analysis plugin never reads it.

## 5. Primary measurement and units

The primary analytical quantity is:

```text
levoglucosan_ppm
```

It represents levoglucosan concentration in the simulated aqueous filter extract.

For this dilute aqueous demonstration:

```text
1 ppm ≈ 1 mg/L = 1 µg/mL
```

The Dataset also carries the separately derived ambient concentration:

```text
levoglucosan_ng_m3
```

The two quantities are never treated as the same unit.

The synthetic method also records sampled air volume and extract volume so the conversion is reproducible.

---

## 6. Analytical replicates, LOD and LOQ

Each daily site sample has exactly three technical IC replicates.

Replicate noise contains:

```text
relative analytical variation
+
small absolute noise floor
```

The absolute component prevents unrealistically zero uncertainty at low concentration.

The synthetic analytical thresholds are:

```text
LOD = 0.010 ppm
LOQ = 0.030 ppm
```

Below-limit values are not silently replaced with zero. The source Dataset carries explicit below-LOD/below-LOQ information.

For a daily triplicate, the plugin calculates:

- arithmetic mean;
- replicate standard deviation (SD);
- standard error of the mean (SEM);
- two-sided 95% confidence interval using Student's t for `n=3`.

These quantities are intentionally kept distinct. Replicate SD measures technical analytical dispersion, while between-day variability is an environmental/time-series quantity.

## 7. Synthetic seasonal model

The latent campaign model combines:

```text
site baseline
+
seasonal residential biomass-burning component
+
regional temporal variation
+
wildfire contribution
+
small environmental variability
```

The important seasonal behavior is:

```text
winter
→ elevated biomass-burning background

spring
→ decreasing background

summer without fires
→ low background

summer wildfire episodes
→ strong local/regional spikes

autumn
→ gradual return of residential biomass-burning contribution
```

This intentionally avoids the scientifically misleading simplification `summer = always high levoglucosan`.

---

## 8. Synthetic wildfire model

Several deterministic synthetic summer fire events are generated.

Each event has:

- event ID;
- start/end date;
- centroid latitude/longitude;
- severity index;
- synthetic burned-area scale.

The wildfire contribution depends on event severity, monitoring-site distance and temporal event evolution. A nearby site can therefore show a large response while distant sites show a smaller transported response.

The Central-West event is inspired only in broad scale and timing by the historical Montiferru fire. The generated 2025 event itself is synthetic.

## 11. Configurable analytical parameters

### 11.1 Technical-replicate CV threshold

```text
qc_cv_threshold_percent = 10
```

A daily triplicate with CV above this configurable threshold is flagged for the demonstration QC view.

This threshold is a teaching/demo criterion. It is not presented as a universal analytical-method acceptance requirement.

### 11.2 Anomaly baseline window

```text
anomaly_window_days = 21
```

Must be an odd integer >= 3.

A moving median is calculated through the public numerical service and used as a robust local baseline.

### 11.3 Positive anomaly threshold

```text
anomaly_z_threshold = 4
```

Residuals are scaled using a MAD-based robust scale:

```text
robust scale = 1.4826 × MAD
```

Positive scores at or above the configured threshold are flagged.

This is descriptive anomaly detection, not automatic source apportionment.

### 11.4 Cross-site lag range

```text
cross_site_max_lag_days = 2
```

The plugin evaluates pairwise site relationships over signed lags from `-N` to `+N` days.

## 12. Scientific analyses

The plugin transforms replicate-level measurements into reusable canonical derived Datasets.

### 12.1 Daily statistics

One row per day + site, including:

- mean concentration;
- replicate SD;
- SEM;
- Student-t 95% CI;
- fire context;
- below-LOD / below-LOQ counts.

### 12.2 Monthly statistics

One row per month + site, calculated from daily site means. Between-day SD is kept distinct from analytical replicate SD.

### 12.3 Seasonal statistics

Five categories are used:

```text
1 winter
2 spring
3 summer non-fire
4 summer fire
5 autumn
```

### 12.4 Site summary

One row per site, including:

- latitude/longitude/elevation;
- annual mean and annual CI;
- winter mean;
- spring mean;
- summer non-fire mean;
- summer wildfire-period mean;
- autumn mean;
- wildfire enhancement factor;
- below-limit counts.

### 12.5 Fire relationships

The module evaluates:

- levoglucosan vs fire exposure index;
- levoglucosan vs active-fire distance;
- fire-day vs ordinary summer behavior.

Weighted linear regressions use relative weights proportional to inverse squared estimated daily SEM. Estimated SEM is not known absolute measurement sigma; these fits do not claim a calibrated chi-square distribution.

Correlation/regression in the synthetic observations is reported as a relationship, not as an independent causal proof.

### 12.6 Cross-site relationships

For each of the six site pairs the module reports synchronized same-day correlation and sample count.

It also evaluates short signed lags over the configured range. This helps demonstrate shared regional events versus locally timed responses.

### 12.7 Measurement QC

For every daily triplicate the plugin calculates CV% and flags:

- high-CV triplicates according to the configured threshold;
- any measurement below LOD;
- any measurement below LOQ.

### 12.8 Robust anomaly detection

For each site:

```text
daily mean
→ moving-median baseline
→ residual
→ MAD-based robust score
→ positive anomaly flag
```

The resulting Dataset also preserves fire event ID and fire exposure index so the user can inspect overlap between detected anomalies and known synthetic fire context without reading hidden synthetic truth.

## 17. Performance note

The scientific source contains only 4,380 replicate rows and is small for numerical computation.

The most expensive part of a full run can be graphics, especially when all twelve `plot.dataset` variants plus two 3D PNGs are enabled. The current GX-TXT plotting path may spend appreciable CPU time in Tcl preparation/render orchestration for complex non-binary graph data.

To separate numerical analysis from rendering, disable:

```text
render_2d_graphs
render_3d_graphs
```

or enable only the scientific output groups required for the current demonstration.

The plugin does not perform private down-sampling or alter scientific Datasets to hide framework plotting cost.

## 19. Scientific background and literature basis

### 19.1 Levoglucosan and Sardinian seasonality

Atzei et al. studied PM2.5 in Gonnostramatza, Sardinia, using levoglucosan as a biomass-burning tracer. The reported winter/summer contrast is large: approximately `2096 ± 324 ng/m3` in winter and `18 ± 7 ng/m3` in summer at that real study site.

This demonstration uses that result only to support the model structure `high winter residential biomass-burning signal + low ordinary summer background`. It does not copy those measurements into the generated Dataset.

Reference:

- Atzei D., Fermo P., Vecchi R., Fantauzzi M., Comite V., Valli G., Cocco F., Rossi A. *Composition and origin of PM2.5 in Mediterranean Countryside*. Environmental Pollution 246 (2019) 294-302. DOI `10.1016/j.envpol.2018.12.012`.

### 19.2 HPAEC-PAD repeatability and detection performance

Caseiro et al. describe aqueous aerosol-filter extraction followed by HPAEC-PAD determination of saccharides including levoglucosan, with repeatability on the order of a few percent RSD and solution detection limits in the hundredths of µg/mL range for individual sugars under that method.

- Caseiro A. et al. *Determination of saccharides in atmospheric aerosol using anion-exchange high-performance liquid chromatography and pulsed-amperometric detection*. Journal of Chromatography A 1171 (2007) 37-45. DOI `10.1016/j.chroma.2007.09.038`.

Piazzalunga et al. report a simplified HPAEC-PAD levoglucosan method with approximately 4.8% RSD repeatability and lower solution detection limits under their specific setup.

- Piazzalunga A. et al. *A simplified method for levoglucosan quantification in wintertime atmospheric particulate matter by high performance anion-exchange chromatography coupled with pulsed amperometric detection*. International Journal of Environmental Analytical Chemistry 90(12) (2010) 934-947. DOI `10.1080/03067310903023619`.

The generator therefore uses a simple literature-plausible synthetic analytical model rather than reproducing any one published method exactly.

### 19.3 Montiferru wildfire inspiration

ISPRA reported that the historical Montiferru fire began on 24 July 2021 and affected a very large area. The synthetic Central-West event uses only the broad scale and late-July character as inspiration. Event coordinates, 2025 dates and concentration response are generated values.

Reference:

- ISPRA, *ISPRA a supporto del Dipartimento della Protezione Civile per il monitoraggio dell'incendio scoppiato nell'area del Montiferru nell'Oristanese*, 2021.

### 19.4 Geographic reference

The Regione Autonoma della Sardegna Geoportale was used during development as a reference for locality/geographic convention. Generated locations remain synthetic monitoring reference points, not official stations.

## 20. Interpretation limits

This demonstration is intentionally broad, but it has strict scientific limits:

- all generated measurements are synthetic;
- four sites do not constitute a dense spatial survey;
- 3D triangulation is not spatial interpolation;
- correlation does not independently establish causation;
- the anomaly detector identifies unusual positive departures, not emission sources;
- one biomass-burning marker is not sufficient for quantitative source apportionment;
- the QC CV threshold is configurable demonstration logic, not a universal laboratory acceptance criterion;
- synthetic truth is reserved for generator/test validation and is not used by normal analysis.

## Statistical interpretation in 1.3.0

Daily, monthly, seasonal and annual summaries now retain the public CORE
statistical table, stable row identities, units and conditional assumptions in
every derived or plotting Dataset. Numeric supplies each mean, SD, SEM and exact
Student-t quantile once. Reported confidence limits are the untruncated interval;
the earlier lower-limit clipping and private t approximation are removed.
Canonical Dataset and variable IDs are unchanged. Original Sessions and earlier
release artifacts are not rewritten; rerunning explicitly updates this module's
owned derived outputs as before.

Daily intervals assume independent Gaussian technical errors. Monthly, seasonal
and annual teaching intervals additionally assume independent daily observations;
seasonal/fire structure can violate that assumption. No empirical coverage or
causal claim is made. Graph labels identify these conditional intervals.

Correlations use the public Pearson estimator directly, with CORE zero-variance
semantics. Fire regressions use relative SEM-derived weights, not known absolute
sigma. The descriptive anomaly score retains the earlier normalization
`max(1.4826 * raw MAD, 1e-9)` and QC retains `100 * SD / max(mean, 1e-12)`; these
are teaching conventions without a probability or universal acceptance claim.
MAD and arithmetic are performed through Numeric. CORE records preserve median
and MAD meaning, units and the raw scaling convention.
