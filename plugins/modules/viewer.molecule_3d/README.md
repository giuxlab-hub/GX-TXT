# Molecule Viewer

Open the Molecule Viewer from the Viewer menu in a Session. In **Library &
import**, install any of 30 wwPDB Chemical Component Dictionary references,
import local SDF/MOL, XYZ or PDB, or request a 3-D conformer from PubChem.
The library's original SDFs are CC0-1.0 (wwPDB archive usage policy). PubChem
lookup is online and user triggered; individual external data source rights
remain with their providers.

In **Structure**, choose a Dataset and conformer, then open a Native 3D
ball-and-stick or space-filling representation. The atom table and coordinate
projection allow selection; select exactly two, three or four atoms before
requesting a distance, bond angle or dihedral. Measurements use source
coordinates in ångström. SDF bond order and formal charge appear in the bond
and atom tables. The source tab exposes canonical payload and RAW SHA-256,
license, source URL, query and retrieval date when available.

Use **Save view** to retain the selected Dataset, conformer, style and label
setting in the Session. The generated VTP mesh is a derived display artifact
whose SHA-256 is checked by the Viewer Provider; original molecular bytes are
retained and checked through the canonical Dataset payload. Native 3D owns
camera, zoom and fit controls; molecular semantics remain in this viewer.

## Reference rights

The 30 bundled SDF files are individual wwPDB CCD ideal-coordinate records.
The [official wwPDB/RCSB usage policy](https://www.rcsb.org/pages/usage-policy)
states that PDB archive data files are CC0-1.0. `library/manifest.tsv` records
the exact source URL and SHA-256 of every original SDF. Citation: wwPDB Chemical
Component Dictionary; see also the [CCD download page](https://www.rcsb.org/downloads/ligands).

Dedicated molecular 3D presentations select only the source-bound molecule_main
layer through the public Viewer Provider presentation scope. Other saved Native3D
layers (for example a crystal structure) remain preserved and available in their
own presentations; Native3D Refresh retains the current molecular scope.

P028 Library consultation: the generic Scientific Library Browser can open a
pinned, read-only `library_source` context. CORE Resource Management stages the
exact Library resource after Entry revision/SHA admission; the existing molecule
parser and coordinate projection display its atoms, bonds, charges and conformer.
No Session or canonical Dataset is created by this consultation. Source geometry
is retained verbatim. **Open 3D structure** displays the same source geometry in
an embedded existing Native3D viewport, including with no Session open. Its
ball-and-stick/space-filling mesh is generated by the existing molecule_io helper
inside the Viewer-held managed Resource allocation; CORE admits that exact mesh
SHA and separately retains the original source SHA/Entry revision attribution.
The source conformer ID, index and original geometry fields remain visible.
Orbit, pan, zoom, Fit, Reset and native geometry selection use the same isolated
native renderer as other CORE viewports. Selecting a native geometry point uses
the existing atom-selection and original-coordinate measurement code. Display
colors map the actual element scalar through the renderer's current color map.
No Dataset, fake Session, saved scene or Workspace entry is created. Changing
conformer/style rebuilds only the derived display; source bytes/coordinates stay
unchanged. In Library mode Save view is disabled; close disposes the viewport and
releases its source/mesh allocation. Requires P028 NATIVE_3D_GUI_HOST_API_v2
managed_artifact capability. Normal Session Dataset import/view/persistence
retains its existing behavior.
