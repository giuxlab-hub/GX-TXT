# NMR Spectrum Analysis

This dedicated NMR Analysis consumes a canonical one-dimensional `spectrum.scientific` Dataset with `spectral_x` in ppm. It selects a declared chemical-shift region, uses the public NUMERIC API for constant-median or linear baseline correction, peak detection and trapezoidal integration, normalizes by the maximum absolute corrected intensity, and publishes processed, peak-list and integral Datasets through Dataset Publication API v2. The source Dataset remains unchanged.

The peak list is numerical evidence, not an automatic molecular assignment. FID processing and phase settings are recorded by `acq.nmr`; inspect them and the original JCAMP source before scientific interpretation.

The default 131,072-sample analysis limit covers the full selected regions of the supplied real DEMOs. Baseline, normalization, processed Dataset publication and integration use every imported sample. Public Numeric peak prominence search is bounded to 8,192 extrema-preserving samples by default because that generic algorithm scans local baselines for each candidate peak. Each block retains its exact measured maximum and minimum coordinates, so narrow line apices remain at their acquired ppm positions; reported widths on this reduced search grid are approximate. A separate `*.nmr.display` Dataset uses at most about 4,096 extrema-preserving points for responsive Plot Dataset rendering and overlays. It is explicitly marked as display data; all quantitative integration uses the full processed Dataset. The report records full analysis stride, peak search mode and sample count. If a user lowers `max_analysis_points` below a source region's size, the whole analysis becomes reduced resolution and the report records that stride.
