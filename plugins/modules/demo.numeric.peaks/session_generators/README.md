# Session Generator package

`gxtxt_numerical_examples_peak_detection_1.0.0.zip` is the portable GX-TXT Session Generator API v1 package corresponding to this plugin.

Canonical destination:

```text
Library: GX-TXT Numerical Examples
Category: Mathematics
Generator: Peak Detection
```

Import it with the GX-TXT Session Generator `Library Manager` using `Import Generator...`. The generated Session is independent of the generator package after creation.
