# Bundled Session Generator

`gxtxt_numerical_examples_welch_psd_1.0.0.zip` is a portable GX-TXT Session Generator for the established **GX-TXT Numerical Examples** library.

Generator ID: `welch_psd`  
Category: `Signal Processing`  
Suggested Session: `welch-psd-example`

It creates `raw/welch_psd_demo.csv`, ground truth and a student exercise. Import the generator through the normal Session Generator Library UI/API; do not unpack it into a Session manually.
