# Scientific Frame Preview 1.0.1

This genuine Builder-authored compiled C++ Preview uses the current canonical
Dataset and existing public Plot/Native2D, numeric-array and metadata owners.
It does not implement a parser, renderer, publication or private filesystem API.
The module is independent of importer identity/version. Install matching P033
CORE public native-client facilities and enable the module through ordinary
Preview Configuration; installation does not silently enable a new Preview.

Local controls browse actual Variable batches, exact C-order values hyperslabs,
Metadata and Source metadata. Explicit First Variable is user enumeration, not
a scientific-axis default. Canonical values/coordinates/units are rendered by
CORE; no first16 event sample, invented index X or flattened frame is substituted.
The frame uses actual Variable/dimension IDs and strict JSON fixed-axis indices.
All actions are presentation only; source/scientific payload remains unchanged.

This private candidate still requires actual native/public/scientific/GUI/cold
and independent gates. Source/AST or generic headless Test alone is not runtime
availability or scientific acceptance. Unavailable capabilities explicitly refuse.

Version1.0.1 stacks the four canonical plane selectors in full-width rows. The shared vertical container reaches the image and original Source inspector at large fonts; the matching CORE image owner supplies integer nearest-cell Fit and100%/zoom. Independent final GUI/scientific acceptance is separate from source authoring.
