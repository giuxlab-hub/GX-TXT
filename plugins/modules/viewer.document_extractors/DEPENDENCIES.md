# Dependencies

## GX-TXT public services

- CORE Dataset Preview API v1
- CORE Preview Descriptor API v1
- Viewer Provider API v1
- Dataset File Publication API v1
- Dataset Publication API v2
- Dataset Metadata API v1
- `OCR_LAYOUT_API_v1`
- `TABLE_EXTRACTOR_API_v1`

The viewer plugin does not invoke Tesseract, Poppler, ImageMagick or other document tools directly.
