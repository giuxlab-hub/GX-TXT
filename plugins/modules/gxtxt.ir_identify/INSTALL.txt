gxtxt.ir_identify module version: 2.0
GX-TXT Pipeline remains v0.7.9.

Install:
  copy directory gxtxt.ir_identify
  to <GX-TXT>/plugins/modules/gxtxt.ir_identify

Requirement:
  gxtxt.ir_waveform v3.3 must also be installed.

Workflow:
1. Import/acquire the waveform.
2. Run gxtxt.ir_waveform for the primary IR signal.
3. Run gxtxt.ir_identify with the same dataset and signal binding.
4. Inspect protocol_identification.txt and the diagnostic graphs.

The module deliberately refuses to invent a protocol when no matching waveform-analysis manifest exists.
