# Electromagnetic Simulation CORE

The public `ELECTROMAGNETIC_SIMULATION_API_v1` models linear planar static electrostatics and magnetostatics. Native C++ validates SI geometry, materials, excitation and mesh resolution; Gmsh creates the actual triangular mesh and GetDP solves the finite-element problem. Solver executable configuration belongs to Configuration → Runtime.

`defaultModel`, `validate`, `saveModel`, `listModels` and `loadModel` use existing Session Interactive Documents and Workspaces. `runAsync` submits the registered scientific provider to the durable CORE Job supervisor. `jobStatus`, `cancel`, `resultDescribe` and `resultPreview` query its public typed state and bounded opaque output APIs. Closing a Viewer does not transfer or create a new Job owner. Unsupported pause is not presented as implemented.

`publish jobId datasetId` explicitly publishes two create-only canonical Datasets: cell-centered fields under the requested ID, and exact nodes under `<ID>_nodes`. Their metadata links both identities. An atomic existing Publication batch protects failure rollback. Node identities, positively oriented triangle connectivity, region/material identities, original solver resources and complete source provenance remain distinct from centroid samples. Scalar potential samples are triangle averages of the actual nodal solution; vector fields are the actual piecewise-constant first-order FEM field. There is no nodal interpolation of cell data.

The electrode model imposes 0 V on the left, the applied voltage on the right and natural insulating upper/lower boundaries. The homogeneous ideal reference is `Ex = -voltage/(2*half_width)`. The magnetic model places a round uniformly current-carrying axial conductor inside rectangular air, with linear relative permeability and outer `Az = 0`. Its finite outer boundary affects the field. Native checks independently assemble the free-node weak residual and report the actual GetDP residual. Magnetic validation also evaluates the piecewise-constant field on a circular Ampere loop and compares its integral with the enclosed mesh current; it does not interpolate the field.

Only bounded planar static linear models are supported. Axisymmetry, nonlinear B–H, transient electromagnetics, arbitrary CAD, three-dimensional device inductance, terminal extraction and SPICE generation are unavailable. Mesh refinement tests must use actual separate solver runs; no analytical formula substitutes for solver output.

The GetDP absolute residual is a norm of its assembled, possibly scaled linear system. The independently assembled relative weak residual is dimensionless. Neither residual is a physical uncertainty or a stand-alone estimate of field accuracy; use explicit physical references and mesh dependence for that assessment.

The node Dataset also preserves the actual solved nodal potential (`V` or `Wb/m`); it is not reconstructed from cell averages. Region and material IDs remain explicit integer columns. `fieldDescribe datasetId` resolves authoritative published role metadata for independently written consumers, including the linked node Dataset, potential, field components, scalar magnitude and connectivity variables.

The module's provider entrypoint uses the existing Scientific Execution driver. Its registered native library and worker sources are pinned at preparation and rechecked before execution. Approved raw mesh, generated geometry/formulation, scalar/vector outputs and solver diagnostics are retained through existing managed Resource references in publication metadata. Bounded result previews use opaque public output tokens; the Viewer receives no solver scratch paths. The Python worker is a small required adapter to the existing Python Job supervisor and Tcl/native ABI; all model generation and scientific parsing/checks are C++, and it owns no process launcher or job registry.

## Public operations

Activate `ELECTROMAGNETIC_SIMULATION_API_v1`; Tcl namespace is `::GX::ElectromagneticSimulation`. `defaultModel kind` accepts `electrostatic_2d` or `magnetostatic_2d`; `validate model` returns the normalized model and an explicit validation-only state. `saveModel model ?documentId? ?workspaceName?`, `listModels`, and `loadModel documentId` use Session Workspace identities. `runAsync model ?callback? ?documentId?` returns the existing durable Job ID; host callbacks are optional presentation notifications. `jobStatus jobId` and `cancel jobId` preserve actual CORE lifecycle states. `resultDescribe jobId` reports physical checks, solver versions and native identity; `resultPreview jobId ?offset? ?count?` returns at most 100 cell rows. `publish jobId datasetId` explicitly creates linked canonical node/cell Datasets. `fieldDescribe datasetId` returns actual role metadata; it rejects unrecognized producer data.

Python and Octave use `gxtxt_api_call('ELECTROMAGNETIC_SIMULATION_API_v1', operation, arguments)`. Registered operation names are `api_info`, `default_model`, `validate_model`, `save_model`, `list_models`, `load_model`, `run_async`, `job_status`, `cancel`, `result_describe`, `result_preview`, `publish`, and `field_describe`. Scientific models are typed structs and all dimensions/parameters are SI. The script `run_async` operation has no GUI callback operand. Tk windows and Viewer lifecycle remain host-only; scripts use canonical field publication and public Plot v4 operations.
