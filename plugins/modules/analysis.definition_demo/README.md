# Scientific Analysis API Demo

SPDX-License-Identifier: GPL-3.0-or-later

This module is a deliberately small conformance/example plugin for GX-TXT Pipeline v0.8.4.

The module runner only resolves its runtime paths and calls `gxtxt_analysis_run`. Calculations are described by the selected Scientific Analysis Definition; generic operations are owned by the framework.

For the supplied reference definition:

1. take `gxtxt.ir_waveform`'s `analog_chain_comparison.csv`;
2. import it with `acq.generic_csv` using dataset contract `table.generic` and an ID such as `ir.chain.summary`;
3. enable `analysis.definition_demo`;
4. select `example.ir_chain_metrics_v1`;
5. run the analysis.

The expected result is a CSV, text summary and one grouped bar chart generated by framework operations.


v0.8.3 introduced this small reference module as an opt-in example of Render Cache API v1; v0.8.4 retains that behavior unchanged. It saves a standard `cache` envelope to `render_cache.mat`; no cache-only rerender entry point is declared (`rerender_from_cache=0`).
