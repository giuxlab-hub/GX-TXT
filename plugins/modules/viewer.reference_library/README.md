# Scientific Reference Library

This Session-independent browser uses the CORE Scientific Library Manager. Install a managed package, inspect its provider, version, owner, license, provenance and hashes, search references, verify package integrity, update to a later version, or remove it. The browser shows entry metadata as supplied by a type provider and contains no NMR/IR-specific presentation rules.

Install the measured Cambridge ¹H/¹³C reference package from `library.spectroscopy.nmr.reference/data/cambridge_co2_nmr_1d_1.0.0.zip`. Selecting an IR reference and choosing **Open in specialized viewer** opens that exact spectrum in `viewer.spectral_library`. Its IR-specific compare/ranking features remain in that viewer.
