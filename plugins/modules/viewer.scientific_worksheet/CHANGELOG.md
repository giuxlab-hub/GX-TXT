# Scientific Worksheet changelog

## 1.1.1 — Production GUI usability review

- Added plugin-local fine row and column separators, an active-row cue, clearer selection outline, and a readable formula bar.
- Grouped Workbook, Data, Analyze, Edit, and Calculate controls. The toolbar wraps Analyze and Calculate at narrow widths, and a new window opens within a common 1280-pixel screen.
- Kept Pick Reference visible beside Apply Formula, surfaced sheet actions beside the tabs, and shortened status messages while preserving source identity.
- Reworked Dataset binding, Function Browser, guided-operation, and Plot/Publish dialog presentation. The binding dialog now keeps its action button in view; manual mappings remain available.
- Captured and visually reviewed production Tk images from copied real statistics, interpolation, regression, and mixed text/numeric Sessions. The complete final user guide includes portable plugin-local images.

## 1.1.0 — Scientific workbook and guided math

- Added directly editable cells, rectangular selection, formula-aware fill and paste, undo/redo, multiple sheets, cross-sheet references, and manual or automatic recalculation.
- Added vector and matrix spill, mixed text/numeric Dataset binding, source lineage, sorting and filtering, and public Unit Registry conversion.
- Added a categorized function browser and guided execution for public Numeric, Signal, RF Network and Magnetics operations, including provider-owned declarative callback models and structured result fields.
- Preserved Worksheet plotting through the public Plot Dataset API.
- Validated four copied DEMO Sessions in the production GUI, with saved document and full Session reopen checks. 

## 1.0.0 — Initial Worksheet

- Added safe cell formulas, Dataset and Selection binding, four-provider math access, Plot Dataset previews and retained plots, Dataset publication, and Session document persistence.
