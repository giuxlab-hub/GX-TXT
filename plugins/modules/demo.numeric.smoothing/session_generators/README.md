# Session Generator package

`gxtxt_numerical_examples_smoothing_1.0.0.zip` is the portable GX-TXT Session
Generator API v1 package corresponding to this plugin.

Canonical destination:

```text
Library: GX-TXT Numerical Examples
Generator: Smoothing
Category: Mathematics
```

Import it with the GX-TXT Session Generator `Library Manager` using
`Import Generator...`. See `../MANUAL.md` for the complete GUI procedure.
