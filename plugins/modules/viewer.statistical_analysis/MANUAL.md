# Statistical Analysis Viewer

Open Viewers → Statistical Analysis. Select a scientific Dataset, then a question
from the installed statistical Analysis providers. The catalog supplies methods,
configuration types, defaults and availability. Only fields used by the selected
method are shown. Select scalar Variable IDs from their choices; for repeatable
variable lists enter stable IDs separated by semicolons. Expert settings opens the
existing module Configuration owner. Optional selections use its public selection
contract. Blank selection means the full source.

Run selected method submits exactly that provider through the existing targeted
Standard Analysis queue. It does not enable the provider on Analysis or tick Run.
A disabled Analysis-page module remains an available public service; a genuinely
missing/incompatible provider reports unavailable. Cancel controls that actual
invocation. Descriptive, grouped, weighted, distribution, outliers, correlation,
PCA, hypothesis tests, ANOVA and resampling retain their existing algorithms,
canonical publications, scientific assumptions and reports. Other installed
providers are discovered rather than encoded as a permanent ten-method authority.

Descriptive preview calls Numeric and CORE Statistical Result Semantics without
publishing a Dataset or assuming an uncertainty model. Display source is a shared
Native2D scatter view. Official provider-generated graphs remain with the normal
Plot/Graph owners; Inspect publications and the Results checkbox browser expose
actual canonical outputs and declared scientific reports. No Viewer-private plot
or statistical estimator is introduced.

Workspace state preserves typed values, dynamic choices, source/plot bindings and
invocation identity. Numeric restoration may canonicalize an equivalent floating
literal (for example 0.95 to its binary64 decimal representation); its value does
not change. Session guards prevent applying state to another scientific source.

STATISTICAL_ANALYSIS_VIEWER_API_v1 supplies providers, submit module request,
status module run and cancel module run independently of GUI visibility. Its
headless request uses the existing session token, sources, typed config and
repeatable table snapshots. No Run selection mutation is required.

Import the official design into Viewer Interface Builder to inspect, save,
generate and reimport the complete interface. handlers.tcl is preserved by
regeneration and delegates to the accepted public numerical/Analysis owners.
Safe Preview never starts science. See the dev106 acceptance report for actual
Debian tests, independent numerical evidence and explicitly unverified cases.
